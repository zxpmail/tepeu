# 视觉风格选择器 · v2.2.0

> **平台唯一性**：本技能只编写提示词，不调用任何生成服务。用户另外明确要求实际生成时，只交接 WorkRally MCP，**不得**切换、替换或补充其他 MCP server、第三方生图 API、本地或开源模型、网页版生成工具；风格提示词中也不写入特定平台的专有语法、权重标记或触发词。完整规则见 `workrally-brand-film-pipeline`「平台唯一性规则」。

## 1. 核心定位与边界

插件内所有风格能力的**唯一入口**，合并了原 `asset-style-selector`（资产四风格）、`visual-style-library`（87 种风格库）与 `style-cinematic-realism`（主流程写实基底）。**合并技能，不混合画风。**

- 适用：角色、场景、道具、关键帧的图像提示词；同一资产的多图一致性；已有提示词的定向微调；风格浏览与挑选。
- 不适用：剧本创作、视频时间轴、自动批量生成、模型/API参数探测、文件清理。
- 只编写提示词。只有用户另外明确要求实际生成，才交接 **WorkRally MCP** 的生成能力（不切换到其他 MCP server、第三方 API、本地或开源模型、网页版生成工具）；选择风格本身不代表授权上传参考图或消耗生成额度。
- 本包自包含，无运行时外部依赖。所有相对路径均以本 SKILL.md 所在目录为基准。

## 2. 统一入口

**所有风格请求直接进入同一个 87 种风格库，不再区分 A/B 模式或固定四分支。** 「资产四风格」「四风格选择器」只是此统一入口的旧名称，不恢复旧菜单。

| 用户意图 | 处理 | 规则 |
| --- | --- | --- |
| 主流程 §0F；进入「风格」；「选风格」「推荐风格」；调用旧入口名称 | 从全库推荐：剧情片写实 + 按剧本/需求筛选三项，同时提供「浏览全部风格」 | 5.5 节 |
| 「全部风格」「有哪些风格」「浏览全部」；按分类或关键词查找 | 浏览同一个87种目录，可直接选择未进入推荐菜单的风格 | 第 4 节 |
| 明确点名库中唯一标准名或参考作品 | 匹配目录条目后直接确认选择，不强制再选四项 | 5.4 节 |

- 四项是**本轮推荐**，不是候选范围上限；推荐、全库浏览、直接点名共享同一个风格 ID 与确认记录。
- 写实默认包含在推荐菜单里，不默认选中；后续主流程写实基底只是执行层适配，不是另一个选择入口。
- 同一任务只锁定一种风格。「换个姿势」「只改光线」及恢复同一项目时复用仍有效的确认；新项目不继承旧项目的选择。「换风格」「重新开始」按当前路由重新确认，菜单更新本身不授权重做素材。
- 切换风格先保留用户主体事实，清除旧风格的渲染、布光、色彩与质感词，确认新选择后再重建。

## 3. 对外名称规范（推荐、浏览与直接选择共用）

- 每个风格有一个**标准名**。凡是展示给用户的内容——菜单、选项组件、「已选：…」确认、输出提示词时的风格标注、分类浏览——**只用标准名**。
- 外显内容中**不得出现作品、作者、导演、画师、摄影师、工作室、游戏、品牌名称**（包括英文名与缩写）。菜单里的「画面」「适合」描述由你用中文概括画面特征。
- **标准名有两个等价来源，取其一即可，无需换算**：[风格库目录](references/library/catalog.md) 每行加粗的名称，以及每个风格文件头部的 `- **标准名**：` 字段（H1 标题同为标准名）。两者一致，87 个标准名互不重复。
- 风格文件里的 `- **原名**（内部标识，不外显）`、`风格 ID`、`原目录`、目录中的「原名」、确认别名与文件名（`style-xxx`、`style_id`）**都是内部标识，一律不对外展示**。用户说出原名或参考作品时按原名匹配，回复中改用标准名称呼。
- 风格库文件（`references/library/styles/*.md`）的提示词正文已去除作品、作者与摄影师名，按原文使用。

## 4. 浏览全部风格

1. 在每轮推荐旁提供「浏览全部风格」「按分类查看」「直接输入风格名」的入口；这是导航，不占四个风格推荐名额，也不是第五种风格。组件仅能放四项时，在组件外以文字提供导航。
2. 用户请求全库浏览时，读取 [统一目录](references/library/catalog.md)，按目录的大类/中类展示全部 **87 个标准名**及简短画面特征。只浏览不要求提供剧本，不预读87个风格正文。
3. 单次展示不下时可分页或按分类展开，明确当前分类/页数、剩余数量和下一页入口；遍历后必须覆盖全部87项。用户要求完整列表时输出全量分类目录，不只给四项推荐。
4. 支持按题材、媒介、情绪或标准名搜索；仅从真实目录匹配，允许未在推荐四项中的风格直接入选。无匹配则说明，不造新名称、不随意删库条目；硬约束冲突先说明并确认是否修改约束。
5. 推荐菜单与浏览列表各保存显示编号到目录 ID 的快照；只按当前有效列表解释编号。跨页或回到推荐时显示当前范围，指代不明再询问，不套旧固定编号。
6. 从任一位置明确选定后，记录同一份 `selected_style_id`、标准名和确认来源，进入5.4/5.5执行；「返回推荐」重显本项目的推荐菜单，不更换库或重置已确认风格。

## 5. 全库推荐与选择（87种）

### 5.1 触发

进入「风格」、请求推荐或调用旧入口名称时，按5.5从同一个87种库推荐「剧情片写实 + 三项动态推荐」，并提供全库浏览。用户要求「有哪些风格」「浏览全部」时直接按第4节展示目录，不用剧本缺失阻止浏览。已点名唯一风格（标准名、原名或参考作品）时跳过推荐，按5.4执行；主流程中沿用有效确认与写实基底规则。

### 5.2 怎么挑这 4 种

1. **有上下文先贴合上下文**：从用户已给的主体、题材、用途、情绪、2D/3D/写实偏好中取依据，在 [风格库目录](references/library/catalog.md) 里按标准名、分类和场景关键词筛选。**推荐阶段只读目录，不读取任何风格文件**。
2. **4 种必须差异明显**：原则上来自 4 个不同的中类，且视觉语言不同（如写实 / 3D / 2D / 艺术家风格各一，或同为 2D 时分别是国漫、日漫、美漫、笔触）。不推荐两个几乎同质的风格（如「写实武侠」与「国风武侠3D」只因题材相同就并列时，须说清差异）。
3. **不越过硬约束**：可选项必须符合用户限定的媒介与题材；写实候选与硬约束冲突时按 5.5 标为不可选说明。候选不足时如实说明，不凑数、不从库外编风格。
4. **没有上下文时先补问**：优先复用已有剧本、分镜、产品与用途说明；全部缺失时只问「这次是什么题材或产品，主要情绪是什么？」。不拿固定四项兜底，不编造剧本事实；有足够需求依据即可推荐，不强求完整剧本。
5. 不标「最佳」、不预选、不编造匹配度百分比；编号只对应本轮菜单，无默认选中项。

### 5.3 怎么展示与确认

使用当前环境支持的单选组件或文字菜单，正常展示 4 项，名称为标准名，说明为分类、画面特征及推荐依据；不预选。候选不足或有不可选项时按 5.5 的边界规则展示，不伪造选项来满足组件数量。下方只是展示格式，不是固定风格名单：

```text
为你准备了 4 种风格，请回复编号 1–4 选择：

1. 【标准名】 · 分类（大类 / 中类）
   画面：一句话画面特征（中文概括，不含作品/作者/品牌名）
   适合：适合的主体或用途

2. ……
3. ……
4. ……

这4项只是推荐，你可以选择其中一项，也可以：
- 回复「换一批」：保留写实项、更换其余3项。
- 回复「浏览全部风格」或「按分类查看」：在完整87种库中选择。
- 直接输入风格名：不必局限于这4项。
```

- 每项三行，格式一致，便于横向比较；分类显示大类 / 中类名称，去掉内部备注。候选不足时说明实际数量与原因。
- 首轮只展示菜单并等待，不输出任何提示词正文，不读取风格文件。
- **确认选择**：当前菜单的有效编号、唯一标准名（或原名），或「第二个」这类明确指代才算选定；回复「已选：编号 / 标准名 · 分类」后按 5.5 选择执行路径。
- **换一批**：保留第 1 项，只替换第 2–4 项；新推荐与已展示的动态候选不重复，仍遵守剧本依据与硬约束。候选用尽时如实说明，不循环旧三项冒充新推荐。
- **补充描述**（如「要更暗一点的」「想要国风」）：更新需求依据后，按 5.5 重算动态候选，不把补充信息当成已选风格。
- 「随便」「都行」「继续」、多选或含糊回复不算选定，简短追问一次让用户选编号。用户明确说「你来定」时，按上下文取最贴合的一项并说明理由，再请用户确认。

### 5.4 执行

1. 推荐、全库浏览或直接点名选定后，统一按目录 ID 读取所选的**一个**库文件（`references/library/styles/`），不预读其他风格。主流程选定剧情片写实时只读第6节写实基底作为该库条目的执行适配，不叠加另一份完整提示词。旧 `references/01`–`04` 与 `common.md` 只留作历史参考，不再作为运行分支加载。
   - 沿用主体、动作、场景、机位、比例和输出语言；缺必要主体时才补问，不因从全库选择而重走问卷。
   - 角色图锁身份、场景图锁空间、风格图锁画风；冲突先确认，不因换风格改变人物身份或产品形制。
2. 以该文件「结构化提示词（English · 推荐）」整段为风格底，把用户的主体（人物 / 场景 / 动作）写进场景模块或接在风格句之后。中文模型改用该文件的「中文提示词」，语义与英文主体一致。
3. 「统一质感尾缀」已经写在结构化提示词末尾，不要再追加第二遍；以该风格文件原文为准。
4. 方括号模块可按用户要求替换：`[打光]`、`[色彩]`、`[构图]`、`[画家参照]`、`[场景]`。用户没有要求微调时，保持该风格原文。
5. 按第 7 节输出，风格标注写**标准名**与分类。

提示词结构：**风格 - 相机胶片参数/渲染器 - [打光方案] + [色彩调性] + [构图描述] + [画家参照] + [场景/氛围]**，末尾为该风格的质感尾缀。

### 5.5 全库推荐与确认规则（所有入口共用）

**菜单结构：第 1 项固定「剧情片写实」，第 2–4 项按本次剧本/需求从风格库推荐。** “默认写实”只表示保留一个候选，**不表示默认选中或已获生成授权**。本节是动态候选与选择规则的唯一来源。

1. **第 1 项（固定候选）**：剧情片写实 ·【一】仿真人 / 都市·当代现实。内部使用目录 ID `style-cinematic-realism`；旧 `cinematic-realism` 仅作兼容别名，不以旧菜单编号定位风格。
2. **第 2–4 项（动态候选）**：从剧本/分镜或用户需求提取题材、时代、人物、情绪、主要场景、材质及媒介限制，按 5.2 在 [风格库目录](references/library/catalog.md) 中筛选。推荐阶段只读目录，不读风格文件。
   - 每项写出具体的剧本/需求依据和视觉差异；相关性先于凑齐不同分类。不以雷雨等孤立元素改变全片基调，不用三个同质写实变体凑数；明确要求写实内部比较时可给有实质差异的写实风格。
   - 全部候选去重，第 2–4 项不得再放剧情片写实。旧 A 模式的非写实分支只有确实符合本次剧本时才能入选，不因旧编号或历史选择默认入选。
   - 没有任何剧本/需求依据时按 5.2 补问，不使用固定默认组合。范围内不足三项时如实展示现有候选数量；库或目录不可读时报告缺失，不靠记忆编造。
3. **展示与硬约束**：正常展示 4 项，每项包含标准名与分类、画面特征、对应的剧本事实。可说明最贴合项及理由，但不得预选、编造匹配率或把推荐当成确认。用户明确排除写实时，第 1 项仅作为「剧情片写实（与限定媒介不符，不可选）」说明；组件不支持禁用时放在组件外，仅提供符合约束的动态项，不为凑四个可选项而违背要求。
4. **确认与换批**：编号只解析到**当前推荐或浏览列表快照**；唯一名称在整个87种目录中匹配，未进入推荐四项也可直接选定，不把旧固定编号当作风格ID。记录所选ID、显示范围和确认来源。“换一批”保留写实项、重算另外三项，已展示动态候选不重复；不足时说明，不循环旧三项冒充新推荐。随时可按第4节浏览全部或返回推荐；导航、换批本身不改变已确认风格，明确新选择才更新。
5. **执行**：已有本项目有效确认且作用范围未变时直接复用，不重复弹菜单、不跨项目继承。主流程选定剧情片写实时按第 6 节读取写实基底；其他选择及非主流程独立请求按 5.4 只读所选库文件。编号不决定渲染框架，身份/资产规范仍按主流程分类适配；不混读旧 A 模式文件或叠加两份完整提示词。

## 6. 写实基底（主流程专用）

[references/cinematic-realism-base.md](references/cinematic-realism-base.md)（原 `style-cinematic-realism`）是 `workrally-brand-film-pipeline` 写实项目的固定写实基底与**视频默认摄影常量**的唯一来源，含演员三视图、群演、layout 隔离与资产去噪后缀等主流程接入规则。

- 主流程写实项目按主流程 §1a 读取本文件；视频提示词按 §4a 原样插入其中的「视频默认摄影常量」一次。
- 库中的剧情片写实与本文件对应同一个已选风格；无论从推荐、全库浏览还是直接点名选中，主流程使用同一写实语言，不根据菜单位置决定基底、不叠加两份完整prompt。
- 非主流程的单独写实提示词请求按5.4使用库文件，不强制加载本文件。

## 7. 输出格式

默认用中文说明，并给中英文两份可复制完整提示词；用户明确仅要一种语言时只出该语言。

```text
已选风格：编号 / 标准名（· 分类）
资产对象：主体与任务类型

中文提示词
[已替换所有占位符的完整提示词]

English Prompt
[语义与中文一致的完整提示词]

锁定项：身份、服装、装备、关键材质与风格事实
可调项：本轮允许变化的姿态、表情、场景、打光或机位
规格：已知比例/用途；未知时写“未指定”，不虚构工具参数
```

- 角色多图任务额外提供可重复粘贴的「角色锚点串」。场景、道具任务不强加角色字段。
- 对单轮改稿增加「本轮仅改：…；其余保持不变」。
- 不输出内部 style_id、原名、文件路径、未选风格内容或审计原稿，除非用户询问结构。
- 8K/UE5/ARRI等描述属于画面目标或视觉模拟，不构成实际模型分辨率、真实渲染器或拍摄器材的承诺。

## 8. 必须通过的质量检查

- [ ] 所有入口含旧名称均进入统一87种库；推荐为写实候选加三项动态筛选，不存在独立固定四分支。缺推荐依据先补问，不影响只浏览全库。
- [ ] 每轮推荐都提供「浏览全部风格」；未获推荐的条目也能从全库直接选定。导航不占风格推荐名额，分类/分页遍历覆盖87项。
- [ ] 第2–4项有本次剧本/需求依据、去重且不重复写实项；换批只更换动态项，编号按当前推荐或浏览列表快照解析，不套用旧固定编号。
- [ ] 已获明确选择或复用了本项目有效确认；固定写实候选不等于已选，不因规则更新自动改风格或重做媒体。
