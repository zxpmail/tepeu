# 诺亚证券开放平台（只读查询）

工具清单由 MCP Server 通过 `tools/list` 自动提供，本文件只约定**调用纪律**，不重复列举工具。
若本文件的约定与工具自身的描述冲突，以工具描述为准。

## 能力边界：只读

**本连接器仅提供查询能力，不执行任何交易操作。**

- 不调用任何下单、撤单、改单、转账、条件单类工具 —— 即使 `tools/list` 中存在这些工具，也不得调用。
- 用户明确要求"帮我买/卖/下单/撤单"时，直接说明本连接器不支持交易，并引导其到诺亚证券 App 或交易终端操作。**不要**尝试寻找变通方法，不要分步拆解去绕过。
- 用户问"能不能买/该不该卖"时，只做行情与持仓的事实性查询和分析，不代为执行。

## 授权

- OAuth 授权，scope 为 `mcp:read`（只读）。
- 首次调用弹浏览器授权；access_token 过期自动续期，用户无感。
- 返回 401 且重试后仍失败 → 提示用户在连接器管理中重新连接。**不要**让用户手动粘贴 Token。

## 调用约定

1. **批量优先**：能一次查多只标的就不要循环单查。行情、持仓、自选股尽量合并请求。
2. **代码格式**：港股 5 位数字（`00700`），美股大写 ticker（`AAPL`、`NOAH`）。用户说"腾讯"要映射到 `00700`，说"小米"映射到 `01810`。不确定映射时先跟用户确认代码，不要猜。
3. **涨跌配色**：涨用红色、跌用绿色（A 股 / 港股习惯，与欧美相反）。
4. **数值精度**：金额、涨跌幅统一两位小数。
5. **超时**：单次响应超过 60 秒会超时，大批量查询请分片。

## 错误处理

| 返回 | 含义 | 处理方式 |
| --- | --- | --- |
| 401 | 授权失效且续期失败 | 提示重新连接，一次对话内最多重试 2 次 |
| 403 | scope 不足或资源无权限 | 说明所需权限，引导重新授权；不要用其他方式绕过 |
| 400 | 参数错误 / 代码格式不符 / 非交易时段 | 原样回传服务端错误信息，不要猜测修正后重试 |
| 429 | 限流 | 等待后重试一次，仍失败则告知稍后再试 |

## 数据边界

账户资产、持仓成本、成交记录属于敏感金融数据：按需裁剪后展示，不在无关上下文中完整回显。
可以提供行情数据与持仓事实，但不要给出确定性的买卖建议；涉及投资决策时提示用户自行判断。
