# 儿童视频

**这是什么**：**给孩子看**的视频——睡前故事、绘本故事、儿歌、好习惯养成（刷牙、洗手、过马路、分享）、
简单科普（为什么会下雨、小种子怎么长大）。观众是孩子，陪看的是家长：孩子要看得懂、看得进去，
家长要觉得放心、有收获。核心产物是**一集讲清一件事**的小故事或小节目。

**画面风格不由本品类规定**：卡通、绘本、黏土、3D、真人都可以，用户选什么就是什么。
本品类管的是「给孩子看」这件事本身——语言、节奏、内容安全。

**不属于本品类**：
- 讲给家长听的育儿知识 → 知识科普（`knowledge-explainer`）；
- 童装、玩具、早教课程的推广 → 广告片 / 电商带货；
- 以孩子为主角、但拍给大人看的剧情（萌娃日常、亲子小剧场）→ 短剧。

## 各环节细则去哪看

**这张表是唯一的指引** —— 文件名由本品类自己定，读之前照这里对，不要凭约定猜。
需要哪个环节就读哪一份（都在本目录下）：

| 环节 | 文件 | 谁在什么时候读 | 里面有什么 |
| --- | --- | --- | --- |
| 访谈与落库参数 | `interview.md` | 访谈环节：建项目 / 建下一集，开口问之前 | 年龄段、这一集讲的那一件事、单集还是系列 |
| 编剧 | `script.md` | 剧本师：动笔之前 | 按年龄段的语言、重复与节奏、内容安全、素材清单列什么 |
| 分镜 | `storyboard.md` | 分镜师：动笔之前 | 节奏缺省放慢、画面干净、不闪 |
| 素材 | `asset.md` | 素材师：动手之前 | 主角、场景、音色怎么写 |

⚠️ **通用的东西不在这里**：台词怎么写、人物怎么立、表演怎么写、字段清单与落库流程、
合规红线——那些对所有品类都一样，已在各角色的通用细则里。这几份只有**儿童视频特有的**部分。

## 落库字段这样填

- `story_mode`：**缺省 `anthology`**——每集一个独立完整的小故事，主角可以跨集反复出现（系列 IP 也是这样）。
  只有用户明确要「连着讲的长故事、下一集接着上一集」才用 `serial`。
- `finale_style`：**恒 `closed`**——给孩子的故事每集都要收干净，不留悬念、不留不安（睡前故事尤其如此）。
- `is_finale`：`anthology` **恒 `false`**；`serial` 按通用规则问。

⚠️ `story_mode` 用户没提就直接填 `anthology`，不问；`finale_style` 不问；这几项复述里不出现。
