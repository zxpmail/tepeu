# 广告片

**这是什么**：为**投放**服务的短片。它的成败不看观众喜不喜欢，看**完播与转化**：
有没有在前 3 秒留住人、有没有把一个诉求打进去、有没有让人知道下一步做什么。

**不属于本品类**：讲故事的剧情短剧（那是 `short-drama`）、给公司做形象展示的长片
（`corporate-promo`）、详情页里的产品讲解（`ecommerce-promo`）。
边界判据：**这条片子是拿去买量投放的吗**？是 → 本品类。

## 各环节细则去哪看

**这张表是唯一的指引** —— 文件名由本品类自己定，读之前照这里对，不要凭约定猜。
需要哪个环节就读哪一份（都在本目录下）：

| 环节 | 文件 | 谁在什么时候读 |
| --- | --- | --- |
| 访谈与落库参数 | `interview.md` | 访谈环节：建项目 / 建下一条，开口问之前 |
| 编剧 | `script.md` | 剧本师：动笔之前 |
| 分镜 | `storyboard.md` | 分镜师：动笔之前 |
| 素材 | `asset.md` | 素材师：动手之前 |

## 落库字段这样填

- `story_mode`：**恒 `anthology`**——每条广告独立投放，不承接、不积累剧情记忆
- `finale_style`：**恒 `closed`**（每条都要有明确的行动落点，开放式留白与转化目标冲突）
- `is_finale`：**恒 `false`**

⚠️ 这三项**不问用户**，直接填，复述里不出现。

## 一个项目 = 一个投放方向，一条 = 一个素材

同一个项目下的多条通常是**同一诉求的不同版本**（15s / 30s 版、不同开头的 A/B 测试）。
用户说「再做一版换个开头」时，就是在这个项目下建下一条，项目级设定全部沿用。
