# 电商产品宣传

**这是什么**：挂在商品链接上、或用来带货的视频。观众已经在看这个商品了，
他们要的是「值不值得买」的判断依据——**演示、对比、规格、使用效果**。

**不属于本品类**：买量投放的广告素材（`commercial-ad`，观众还不知道你是谁）、
公司形象片（`corporate-promo`）、剧情类内容（`short-drama`）。
边界判据：**观众是不是已经在看这个商品了**？是 → 本品类。

## 各环节细则去哪看

**这张表是唯一的指引** —— 文件名由本品类自己定，读之前照这里对，不要凭约定猜。
需要哪个环节就读哪一份（都在本目录下）：

| 环节 | 文件 | 谁在什么时候读 |
| --- | --- | --- |
| 访谈与落库参数 | `interview.md` | 访谈环节：建项目 / 建下一条，开口问之前 |
| 编剧 | `script.md` | 剧本师：动笔之前 |
| 分镜 | `storyboard.md` | 分镜师：动笔之前 |
| 素材 | `asset.md` | 素材师：动手之前 |

## 落库字段这样填

- `story_mode`：**恒 `anthology`**——每条独立挂在不同链接或不同平台
- `finale_style`：**恒 `closed`**（必须落在下单引导上）
- `is_finale`：**恒 `false`**

⚠️ 这三项不问用户，直接填，复述里不出现。

## 一个项目 = 一个商品，一条 = 一个用途

同项目下的多条通常是同一商品的不同用途：主图视频（通常静音播放、9-30 秒）、
详情页长视频（60 秒讲透）、带货短视频（口播、30 秒）。
用户说「再做个详情页版」就是建下一条，项目级设定沿用。
