# 企业宣传片

**这是什么**：给**组织**做形象呈现的片子。观众是客户、合作方、投资人或应聘者，
他们要的是「这家公司靠不靠谱」的判断依据——**事实、规模、流程、人**，不是情绪。

**不属于本品类**：卖某个具体产品（`ecommerce-promo`）、拿去投流买量（`commercial-ad`）、
有剧情的品牌微电影（`short-drama`）、
给自己员工看的内训与制度培训（`course-training`）、年会上送给员工的祝福（`greeting-video`）。
边界判据：**这条片子是在介绍一个组织、而不是一件商品吗**？是 → 本品类。

## 各环节细则去哪看

**这张表是唯一的指引** —— 文件名由本品类自己定，读之前照这里对，不要凭约定猜。
需要哪个环节就读哪一份（都在本目录下）：

| 环节 | 文件 | 谁在什么时候读 |
| --- | --- | --- |
| 访谈与落库参数 | `interview.md` | 访谈环节：建项目 / 建下一集，开口问之前 |
| 编剧 | `script.md` | 剧本师：动笔之前 |
| 分镜 | `storyboard.md` | 分镜师：动笔之前 |
| 素材 | `asset.md` | 素材师：动手之前 |

## 落库字段这样填

- `story_mode`：**恒 `anthology`**——各版本互相独立
- `finale_style`：**恒 `closed`**（必须落在明确的结论与联系方式上）
- `is_finale`：**恒 `false`**

⚠️ 这三项不问用户，直接填，复述里不出现。

## 一个项目 = 一家公司，一条 = 一个版本

同项目下的多条通常是**同一家公司的不同用途版本**：3 分钟完整版、
60 秒展会循环版、30 秒招聘版。用户说「再剪个短版」就是建下一条，项目级设定沿用。
