# 小红书爆款笔记创作法

本技能依赖连接器 `tuwen-creator` 暴露的 10 个工具。生成一篇笔记的标准流程：

## 1. 明确需求（不要直接开始生成）

先确认三件事，缺一项就追问用户：
- **主题**：写什么（产品 / 场景 / 观点）
- **形态**：`type=short`（小红书笔记，300–800 字）还是 `type=long`（公众号长图文，1500 字以上）
- **素材来源**决定 `mode`：
  | 用户给了什么 | mode | sourceContent |
  |---|---|---|
  | 只有一个话题 | `topic` | 不填 |
  | 一篇参考文章或公开链接（要仿写） | `article` | 正文或 URL |
  | 一份大纲 / 要点 | `outline` | 大纲文本 |
  | 零散想法、聊天记录 | `idea` | 原样贴入 |
  | 要结合自家产品卖点 | `knowledge` | 先 `list_products` 拿 `productId` |

## 2. 生成前的两个查询

- `get_account_overview`：确认积分余额。文本生成免费；如用户要配图且余额低于 `imageCost`，提前告知并引导 `redeem_invite_code`。
- `list_templates`：如果有匹配的模板（探店 / 好物清单 / 深度评测 / 品牌故事），把模板 `structure` 概括进 `tone` 或在 `sourceContent` 里给出结构要求。

## 3. 调用 `create_note`

参数建议：
- `topic`：把用户话题改写成**有钩子的标题方向**，而不是原话。可用公式：数字 + 人群 + 结果（"上班族 3 分钟搞定的 5 款营养早餐"）、反常识（"越贵的护肤品越不适合你"）、痛点 + 解法（"总是拖延？我用这 1 个方法治好了"）。
- `tone`：给具体风格词，如 `亲切种草`、`专业干货`、`闺蜜安利`、`理性测评`。
- `keywords`：用户强调的品牌词 / 搜索词，逗号分隔，便于 SEO。

## 4. 交付与润色

拿到正文后按小红书阅读习惯整理再呈现给用户：
1. 首行标题 ≤ 20 字，含 1–2 个 emoji
2. 正文分 3–5 段，每段一个小标题 + 2–4 句，段间空行
3. 结尾 3–6 个话题标签（`#关键词`），第一个用最大类目词
4. 提示用户：作品已保存到平台「我的作品」，可在网页端继续编辑 / 配图 / 导出

若用户要改：用 `update_content` 更新标题或正文（传作品 `id`），不要重新生成整篇。

## 5. 错误处理

| 返回 | 含义 | 做法 |
|---|---|---|
| `INSUFFICIENT_CREDITS` | 积分不足以生成配图 | 说明规则，询问是否有邀请码 → `redeem_invite_code`；或建议先只生成文本 |
| `不允许访问本机或内网地址` | 用户给的链接指向内网 / 本机 | 请用户提供公开可访问的链接，或直接粘贴正文 |
| `无法提取链接内容` | 目标页面反爬或需登录 | 请用户复制正文后用 `article` 模式 |
| 401 Unauthorized | 密钥无效或已吊销 | 引导用户在平台「设置 → 开放 API」重新创建并填入连接器 |

## 6. 批量选题

用户要"给我出 5 个选题"时：先用 `list_contents` 看历史作品避免重复，再给出 5 个带钩子的标题，等用户挑选后再逐篇 `create_note`，不要一次性生成 5 篇（消耗大且多数会被弃用）。
