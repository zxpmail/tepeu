# 疾病 ICD 查询

用户需要核对疾病标准名称、诊断描述，或在病案、统计工作中查找 ICD 术语及编码候选时，使用 `search_disease_icd`。仅提供症状并要求诊断时，不将其直接转换成编码查询。

## 连接与调用

使用已连接的“丁香园医学检索”MCP 连接器。未连接或授权失效时，引导用户通过 WorkBuddy 连接或重新授权；凭证与刷新由客户端管理，不索取 token，不通过 shell 或 HTTP 替代 MCP 工具。

根据用户自然语言意图触发，无需选择场景胶囊。

以用户原始检索问题作为必填字符串 `query`，保留疾病名称、病因、部位、并发症、急慢性、分型、编码、版本和地区要求。输入不能为空白，不添加分页、数量、版本筛选或客户端 IP 参数；用户提出的版本要求只能放入 query，接口不保证按该条件过滤。

描述过于宽泛且可能对应不同疾病或分型时先追问；用户希望先看候选时可查询一次并提示其确认。

一次请求调用一次本工具，不因空结果、候选不足或超时自行重试，不自动调用其他工具补齐结果。用户明确要求重试时再发起查询。

调用示例（仅为请求，不代表真实结果）：

```json
{"query": "查询 2 型糖尿病的 ICD 编码"}
```

## 结果处理

先检查 MCP `isError`；成功时解析 `content` 中 text 的 JSON 数组。没有分页或总数字段，默认按返回顺序展示前 5 条，用户要求时可展示本次返回的更多候选。

| 字段 | 展示规则 |
| --- | --- |
| `sourceType` | 固定为 `terminology` |
| `documentTitle` | 术语标题，原样展示 |
| `publishDate` | 保留返回日期文本，不猜测精度、时间戳单位或时区 |
| `textChunk` | 来源文本片段，保留编码、限定条件和换行，不补写缺失内容 |
| `url` | 有值时作为来源链接 |

空字段省略。当前没有独立的 `icdCode`、`icdName`、版本或地区字段，只把标题和文本片段作为来源内容展示，不从中推断、提取或补全独立的编码结论；不从模型记忆补齐编码，不把发布日期视为 ICD 版本，也不宣称候选是唯一正确或适用的编码。需要版本或地区判断但来源未说明时，明确指出本次结果未提供这些信息。

每条结果可按“标题 → 日期 → 来源文本 → 来源链接”展示；多条候选保留差异，不擅自合并。检索结果用于查阅术语，不能依据症状推断患者诊断或代替正式病案编码确认。

## 空结果与错误

- 成功空数组：说明“本次未返回疾病 ICD 结果”，可建议补充疾病全称、解剖部位、病因、分型、并发症、急慢性、已有编码或版本要求，不断言疾病没有编码。
- `isError=true` 或超时：说明查询失败，错误文本不能当作术语；不展示猜测结果。
- `query 不能为空`：补齐检索需求后再查询。授权失效时回到 WorkBuddy 重新连接。
