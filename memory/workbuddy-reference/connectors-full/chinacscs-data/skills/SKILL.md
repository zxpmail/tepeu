# 中证数智企业数据 Skill

本 Skill 提供中证数智平台 70+ 个数据查询工具的统一入口，采用「语义检索 + 精准执行」两阶段架构。

## 核心调用流程（必须遵守）

1. **先检索**：将用户的自然语言问题原样（或稍加改写补充数据域关键词）传给 `find_tool`，获得相似度最高的前 5 个候选工具；
2. **再执行**：从候选中选出最匹配的工具，按该候选返回的参数定义构造参数，调用 `call_tool` 获取结果；
3. **不理想则改写重试**：若候选工具与问题不匹配（如查财务却返回工商工具），在问题中补充数据域关键词（见下方数据域清单）后重新调用 `find_tool`；
4. **禁止**跳过 `find_tool` 直接猜测工具名调用 `call_tool`。

## 可用工具

### find_tool - 检索数据查询工具

根据用户问题检索最合适的数据查询工具，返回相似度最高的前 5 个候选（含工具名、描述、参数定义）。

**参数**：以工具实际暴露的 inputSchema 为准（用户的自然语言查询问题）。

**使用示例**：
- 查工商：问题中包含"工商登记 / 股东 / 法定代表人 / 注册资本"
- 查风险：问题中包含"失信 / 被执行人 / 行政处罚 / 经营异常 / 股权出质"
- 查财务：问题中包含"资产负债表 / 利润表 / 财务指标 / 业绩预告"

### call_tool - 执行数据查询

调用 `find_tool` 返回的指定工具并返回查询结果。

**参数**：以工具实际暴露的 inputSchema 为准（目标工具标识 + 该工具的结构化查询参数）。

**使用示例**：
- 企业类查询通常需要：企业名称/统一社会信用代码 + 分页参数（pageIndex/pageSize）
- 区域类查询通常需要：行政区划代码 + 指标编码

## 数据域清单（构造检索问题时参考）

| 数据域 | 典型内容 |
|--------|----------|
| 工商基础 | 工商登记、股东投资、人员信息、关联关系、变更年报 |
| 风险信息 | 失信违法、司法涉诉、行政处罚、股权风险、税务风险、经营异常、资产抵押 |
| 财务数据 | 资产负债表、利润表、现金流量表、财务分析指标、业绩预告 |
| 舆情动态 | 企业公告、负面新闻监测 |
| 中证特色 | 敞口映射、敞口分类、经营量化指标、指标定义 |
| 区域数据 | 四级行政区划字典、区域经济财政债务指标 |

## 认证说明

- API Key 需用户在中证数智控制台「API 密钥」页面生成：https://ds.chinacscs.com/dashboard/api-keys
- 凭证仅存储在用户本机 `~/.workbuddy` 下，不会上传云端
- 遇到 401 / 鉴权失败错误时，提示用户到 WorkBuddy 连接器设置中更新 API Key

## 注意事项

- 列表类结果有分页，默认只返回第一页；需要更多数据时递增 pageIndex
- 查询前若只有企业简称，优先用工商基础域工具确认完整企业名称/信用代码
- 避免无目标的批量扫描式调用（如遍历全量企业），按用户具体问题精准查询
