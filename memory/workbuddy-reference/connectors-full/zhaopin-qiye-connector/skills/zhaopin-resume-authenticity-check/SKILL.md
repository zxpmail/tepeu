# 智联招聘｜简历真实性核验

## 目标与边界

本 Skill 面向招聘人员和猎头顾问，对用户明确提供或明确授权使用的本地简历正文、结构化简历或人工摘录进行内部一致性与文本风险检查。交付物用于辅助人工访谈和材料核验，包括可定位的线索、材料依据、合理替代解释及最小核验问题。

本 Skill 不读取智联人才库或任何外部系统，不进行背景调查，不查询外部履历，也不验证候选人的身份、任职、学历、业绩或其他事实。它不自动联系候选人或第三方，不改变候选人状态，不导出或转发材料，不作录用、淘汰或真实性结论。

不得将任何单一信号写成“真实”“虚假”“造假”或“AI 生成”的结论。语言风格、简历版式、非母语表达、行业术语、学校、年龄、性别、婚育、地域及其他与岗位无直接关系的个人特征，均不得单独作为核验依据。

## 适用与不适用场景

适用于以下请求：

- 检查一份已授权简历中需要澄清的时间线、经历、项目或成果表述；
- 整理简历内的前后不一致、重复表述或信息不足之处；
- 围绕目标岗位重点，生成与经历、项目、成果和个人贡献相关的核验问题。

不适用于以下请求：

- 查询外部履历、联系前雇主、学校或第三方，或模拟背景调查；
- 对候选人进行诚信评级、真实性概率打分、自动筛除或录用排序；
- 基于受保护特征、与岗位无关的个人信息或缺少材料依据的猜测作出判断；
- 读取未由用户提供或未获授权的候选人资料、消息、账户或人才库数据。

## 输入与澄清规则

### 最小输入

- 经授权使用的简历正文、结构化简历或人工摘录；
- 可选：目标岗位重点或用户指定的核验范围。

只请求完成当前检查所需的最少内容。默认不复述联系方式、身份证件、精确住址、账号凭据、家庭信息及与当前核验无关的敏感个人信息。

### 必须澄清或停止的情况

| 情形 | 处理方式 |
| --- | --- |
| 材料来源、处理目的或授权范围不清 | 停止处理个人材料，说明需确认的授权和目的；可提供空白模板。 |
| 文件无法读取或内容不完整 | 说明可检查的范围与无法提取的部分，请用户粘贴最小必要文本或提供可读材料。 |
| 简历仅含局部经历 | 仅检查可见部分，不将结果扩大为完整简历或候选人真实性判断。 |
| 用户要求外部查询、联系或招聘处置 | 说明该请求超出本 Skill 范围，不模拟执行。 |

## 核验方法

1. **确定范围**：说明材料类型、可检查部分、缺失部分及本次核验目标；不以常识补全未提供信息。
2. **检查时间线与经历一致性**：关注任职、项目、教育时间的重叠或空档，职位、职责及跨段经历之间的可定位不一致；同时列出兼职、项目制、集团内调动等可能的正常解释。
3. **检查项目与成果表述**：关注同一项目或成果的重复出现、量化结果缺少时间/口径/职责背景、本人贡献边界不清，以及技术或业务术语前后冲突。
4. **检查文本与结构信号**：关注高重复句式、关键词堆砌、模板化表达或不自然跳跃。此类信号仅可作为弱线索，必须附合理替代解释，不能独立形成结论。
5. **形成核验问题**：每项问题仅回指已出现的经历、时间、项目、成果或角色表述，优先询问具体情境、本人动作、协作关系、统计口径与可验证产出。

## 输出要求

使用 [简历核验线索简报模板](templates/resume-verification-brief.md) 输出。每条内容必须明确属于以下之一：

| 层级 | 写法要求 |
| --- | --- |
| 材料事实 | 写明简历中的原始表述、所在段落或可定位位置；不将推测写成事实。 |
| 核验判断 | 说明为何需要补充核验，以及判断强度；不得等同于真实性、能力或录用结论。 |
| 待验证项 | 给出合理替代解释与最小核验问题；未提供材料不得自行补全。 |

核验优先级仅可使用“无明显线索”“建议补充核验”“优先人工复核”。优先级描述的是材料核验顺序，不代表候选人质量、诚信程度或真实性概率。

## 权限、数据最小化与安全

- 仅处理用户明确提供或明确授权的材料；授权范围不清时不处理个人内容。
- 仅呈现完成当前任务所必需的信息；输出以候选人代称替代姓名，避免复述非必要敏感信息。
- 本 Skill 为只读分析能力，不写入、删除、导出、外发或保存候选人材料，也不承诺系统留存、审计或删除行为。
- 不展示系统标识、内部配置、凭据、调试信息或未经授权的第三方信息。
- 输出供具有相应权限的招聘人员或猎头顾问复核和使用，不替代人工访谈、材料核验或招聘决定。

## 异常处理

| 情形 | 输出要求 |
| --- | --- |
| 未发现可定位线索 | 说明“基于当前可见材料未发现需优先核验的线索”，同时说明这不构成真实性确认。 |
| 材料相互冲突 | 并列展示冲突来源和位置，列为待验证项；不自行选择其中一方为事实。 |
| 关键信息缺失 | 列出缺失项及其对检查范围的影响，提出最小补充问题。 |
| 授权不清或范围超出 | 停止处理相关个人信息，说明需要确认的授权范围、来源和处理目的。 |
| 高风险招聘决定 | 重申输出仅为辅助核验线索，由具有相应权限的人员作出决定。 |

## 使用示例

- “请检查这份已授权简历的项目时间线，列出需要访谈澄清的地方。”
- “根据这份简历和产品经理岗位重点，生成不涉及隐私的经历核验问题。”
- “请梳理这几段工作经历中重复出现的成果表述，并说明还需要哪些上下文。”

## 发布前验证

- 使用安全模拟材料或获授权材料，覆盖完整材料、局部材料、经历冲突、项目重复及授权不清等场景。
- 对每轮结果检查：是否区分材料事实、核验判断与待验证项；是否提供合理替代解释；是否避免不当结论与非必要个人信息。
- 本 Skill 的 3 个可复用场景见 `playbooks/`；验证材料仅用于内部质量检查，不作为用户交付物。
