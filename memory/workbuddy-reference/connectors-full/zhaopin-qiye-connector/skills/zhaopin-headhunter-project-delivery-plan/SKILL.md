# 智联招聘｜项目交付计划生成

## 目标与边界

本 Skill 面向猎头顾问、交付负责人和项目协作人员，基于用户提供的职位数量、优先级、招聘难度、人才供给判断、客户时限、顾问资源与已知限制，拆解寻访、沟通、推荐、面试推进和 Offer 跟进等阶段的项目计划。

它输出的是可执行且可复盘的计划方案，不预测或承诺候选人数量、到岗日期、Offer 成功率、市场供给或客户决策。它不访问智联职位/候选人数据，不创建项目、不分配系统任务、不发送客户或候选人消息、不更新流程状态。用户未提供的市场信息、客户偏好和资源能力必须列为待确认，不能以行业惯例填充。

## 触发与最小输入

适用于“制定猎头项目计划”“拆解岗位交付节奏”“安排寻访与推荐里程碑”“识别交付风险”等请求。最小输入包括：职位/项目数量、优先级、客户期望时限、已有顾问资源和已知岗位难点。可选输入包括人才画像、客户面试节奏、历史转化、排他期限和关键约束。

若目标、时限、资源或职责分工不清，先按影响程度提出最少澄清问题。不得为完成计划而虚构人才供给、客户承诺、预算、SLA 或商业条款；不得将计划中的目标写成实际结果。

## 工作流

1. **确认项目范围**：列明岗位、优先级、交付目标、客户时限、资源与责任人；未知信息单列。
2. **拆分阶段与产物**：按需求校准、人才画像、寻访启动、初访/评估、推荐、面试推进、Offer/复盘划分阶段，并为每阶段定义可观察的交付物。
3. **设定节奏与检查点**：依据用户已提供的时限和资源安排里程碑、客户同步节点、风险复盘点与调整触发条件；所有预计时间均说明假设基础。
4. **分配责任与依赖**：区分顾问、研究/寻访支持、客户和候选人需要提供的输入；不能把客户决策或候选人回复写成可控任务。
5. **识别风险与预案**：对需求不清、人才池不足、客户反馈慢、面试延后、关键条件变化等风险，给出可选应对和需由用户确认的升级条件。

## 输出契约

默认交付：项目摘要、阶段目标与交付物、节奏与关键节点、角色分工、风险/假设/待确认项、客户沟通计划和计划调整触发条件。输出中区分用户已确认事实、计划建议和待验证项。计划目标不是招聘结果承诺；不隐藏依赖客户、候选人或市场变化的风险。

## 异常与衔接

- 资源与时限明显不匹配时，说明冲突及影响，提供可供用户选择的范围/节奏调整方向，不替用户决定。
- 多个岗位优先级相同但资源不足时，提出需要业务确认的排序问题，不能自行降低某岗位优先级。
- 用户要求创建系统项目、发送周报、联系候选人或查询人才池时，说明超出本纯 Skill 范围。
- 需求诊断与人才画像可作为可选输入，但本包也接受人工填写的项目事实，不形成运行时绑定。
