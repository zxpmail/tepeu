# 智联招聘｜候选人推荐报告

## 目标与边界

本 Skill 面向猎头顾问和需要制作客户推荐材料的招聘人员。它把用户明确提供或授权的岗位/JD、候选人简历、已完成的人岗匹配、猎头初访记录、意愿分析或人工填写事实，整理为面向客户阅读的候选人推荐报告。报告强调岗位相关的经历、证据、动机、约束、差距和待验证项，便于客户继续评估。

本 Skill 不读取智联人才库、账户、历史沟通或平台评价；不代替候选人确认信息，不伪造项目、业绩、薪酬、资格、到岗条件或客户偏好；不将推荐材料表述为录用结论、背景调查结论或真实性证明。它不会发送报告、更新候选人阶段、安排面试或导出任何平台数据。

## 触发与最小输入

适用于“生成候选人推荐报告”“整理推荐材料”“把简历和访谈记录写成客户可读推荐摘要”等请求。最小输入为：已确认的岗位重点、经授权的候选人材料、拟面向的客户/读者和希望说明的范围。可选输入包括人岗匹配结论、结构化初访、候选人意愿分析、薪酬/到岗条件及顾问判断。

若缺少岗位重点，先请求最少的岗位成功标准；若缺少候选人授权材料或来源不明，停止处理相关个人信息。默认不在报告中展示联系方式、身份证件、精确住址、账号凭据、无关家庭信息或其他与客户决策无关的敏感信息。候选人材料可选择匿名代称；任何超出用户授权范围的信息均不纳入报告。

## 工作流

1. **确认报告目的与范围**：明确目标岗位、读者、候选人代称、材料来源和授权边界；不确定的收件范围须标记待确认。
2. **建立事实映射**：将岗位重点与候选人材料中的经历、项目、能力和工作相关条件逐项映射；每一项保留来源。
3. **分层呈现**：把直接材料支持的信息写为事实；把“推荐理由”“客户可能关注点”等写为顾问判断；把缺失、冲突和无法核验内容写为待验证项。
4. **处理差距与风险**：如实呈现岗位要求未被材料支持的部分、候选人明确表达的限制条件和需进一步验证的问题；不为提高推荐效果而删除关键差距。
5. **生成客户可读交付物**：按 `templates/candidate-recommendation-report.md` 输出简洁、可追溯的推荐报告，不附带未授权的原始材料或个人敏感信息。

## 输出契约

默认报告包括：候选人概览（最小必要信息）、岗位匹配摘要、相关经历与项目证据、已表达的求职动机与工作相关条件、推荐理由、主要差距/风险、待验证问题和建议的后续验证方向。

“候选人陈述”“材料显示”等属于事实层；“建议推荐”“客户可能关注”等属于顾问判断层；“待确认/待验证”不能被弱化为确定优势。报告不输出录用结论、候选人总排名、真实性定论、自动筛选结果、法律/平台合规结论或未获授权的联系信息。

## 异常与衔接

- 输入资料不完整时，先输出可完成的报告骨架和缺失清单，不以行业常识补写候选人经历。
- 简历、访谈或意愿材料冲突时，保留冲突来源；可建议向候选人或客户确认，不自行选择版本。
- 上游的访谈记录结构化、人岗匹配和意愿分析可作为可选输入，但本 Skill 必须接受人工填写或授权材料，不强制安装其他包。
- 用户要求投递、发送、更新流程、搜索候选人或获取智联账户数据时，说明该请求不在本包范围，不模拟执行。
