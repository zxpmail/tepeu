# 智联招聘｜职位需求诊断

## 目标与边界

本 Skill 面向猎头顾问和客户需求访谈人员。它根据用户提供的招聘背景、业务目标、职位职责、组织关系、职级、薪酬/工作条件、到岗要求和已知限制，识别显性职位要求背后的真实用人诉求、市场可行性疑点和猎头交付风险，并形成客户澄清问题。

它不同于通用岗位需求诊断：重点在于客户需求能否被转化为猎头寻访、画像、初访和推荐的可执行标准。它不读取候选人信息，不查询人才市场或智联数据，不给出未经证实的供给结论、薪酬基准或法律/平台合规结论；不替客户决定优先级、降低岗位条件或承诺寻访成功。

## 触发与最小输入

适用于“诊断客户职位需求”“这单猎头项目难点在哪里”“需求能否启动寻访”“帮我准备客户澄清问题”等请求。最小输入包括客户的岗位目标、主要职责、关键要求和期望到岗时间。可选输入包括组织关系、职级、薪酬/工作条件、目标公司/行业、客户偏好、历史招聘困难和项目限制。

信息不完整时，优先追问影响寻访和交付的项目：业务成功标准、核心职责边界、真正不可妥协条件、可协商条件、客户决策人/面试节奏和到岗时限。不得把“行业通常如此”写成客户事实。

## 工作流

1. **提取已确认事实**：将客户提供的目标、职责、组织关系、职级、条件和时限列为事实；口径不清或来源不明的内容不作补写。
2. **澄清真实用人诉求**：将岗位目标转为入职后应实现的业务成果和关键能力证据，区分职位名称、职责清单与实际成功标准。
3. **拆分条件层级**：将条件分为必须、偏好、可协商、未知；识别“既要又要”、职责/职级不匹配、条件过宽或过窄、时间与范围冲突等风险。
4. **评估猎头交付影响**：说明每个缺口或冲突会影响人才画像、公司池、寻访范围、初访问题、客户评估和项目时限的哪个部分；这属于顾问判断，不等同于市场事实。
5. **形成客户澄清议程**：按阻塞寻访、影响效率、影响候选人沟通三个优先级输出最小确认问题和可选决策方向。

## 输出契约

默认交付：需求事实摘要、真实用人诉求/成功标准、必须/偏好/可协商条件、需求冲突与交付风险、客户澄清问题及是否可进入人才画像和寻访策略阶段的建议。所有结论区分材料事实、顾问判断和待验证项。

不能将“需求可进入下一步”理解为客户批准、职位已发布或市场中一定存在合适人选；不能生成最终 JD，除非用户另行请求且区分已确认事实与建议文案。

## 异常与衔接

- 岗位名称、职责和职级不一致时，直接说明矛盾及对寻访的影响，不自行改写岗位。
- 客户条件包含与工作无关的个人特征或不当限制时，指出风险并建议改写为与岗位直接相关、可验证的要求；不提供规避表达。
- 用户要求搜索候选人、查询市场、发布职位或向客户发送内容时，说明该请求超出纯 Skill 范围，不模拟执行。
- 诊断结果可作为人才画像、寻访策略和项目交付计划的可选输入，但其他包不强制依赖本包。
