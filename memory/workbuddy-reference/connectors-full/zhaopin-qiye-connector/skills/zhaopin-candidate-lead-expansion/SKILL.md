# 智联招聘｜候选人线索扩展

## 目标与边界

从用户明确提供且有权使用的候选人、公司、岗位、项目或关键词线索出发，基于岗位画像提出相似特征、替代岗位、关键词和来源方向的**探索假设**。相似不等于匹配；本 Skill 不搜索、读取候选人库、抓取社交关系、推断公司关联或生成联系方式，也不联系、导出或入库候选人。

涉及候选人材料时，先确认用户已获授权且材料仅用于本次寻访分析。授权、来源或目的不清时，停止处理个人线索，仅请求最小授权说明或改用无个人信息的岗位/关键词线索。默认不复述联系方式、精确住址、家庭信息、证件、账号或其他无关敏感信息，也不创建日志、档案或外部记录。

## 工作流

1. 识别线索类型与授权状态；绑定用户提供的岗位画像。
2. 分离线索中的直接事实、可迁移推断、探索假设和待验证项。
3. 每条扩展必须回指画像维度或输入线索。只有完全由岗位画像和输入中的直接事实组成的**非个人化检索方向**，才可标记为“精准检索方向”；不得把单一候选人或未核验线索标为“精准候选线索”。凡含有推断、同义扩展、替代角色或缺失硬条件的内容，一律标为“探索方向”或“待验证”。材料未提供或证据不足只能称为“证据缺口/待验证”，不得称为“明确差距/缺失项”。
4. 公司、组织、上下游、相邻行业等关系如未由用户提供，只能写为待验证的探索方向，不得陈述为事实。
5. 不得因为单个候选人的特征而升级岗位画像规则；候选人未提及不等于不具备。
6. 不得从公司名称、产品名称或岗位名称推断 B 端属性、企业软件属性、SaaS/订阅制/收费模式、客户行业、职级、汇报线、在职状态或其他未提供事实；这条同样适用于“探索假设”、关键词和可迁移特征。不得用“某类公司通常如何”补足输入材料。核验问题只可回指画像条件或输入线索：办公地点只确认是否能满足岗位已写明的办公安排，不问现居城市、通勤、搬迁或私人安排。
7. 不做候选人陈述真实性、能力深度或培养潜力的裁决；只记录哪些职责动作已陈述、哪些岗位条件缺少证据。未经用户确认可协商条件时，不提出“培养型/替代推荐/放宽画像”路径，也不要求客户重新定义岗位标准。

## 输出

输出输入线索与授权范围、已知事实、扩展假设、替代岗位/关键词、证据缺口、风险与最多四个最小人工确认问题。替代岗位只作为非个人化检索方向，不附带“培养型”“转推荐”或岗位标准放宽建议。不得输出候选人名单、联系方式、真实性判断、招聘决定或外部搜索结果。没有用户提供的渠道或数据统计时，不预测候选人批量或检索结果。
