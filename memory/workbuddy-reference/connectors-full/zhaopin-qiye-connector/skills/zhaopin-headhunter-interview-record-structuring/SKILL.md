# 智联招聘｜访谈记录结构化

## 目标与边界

本 Skill 面向有猎头初访或深聊记录整理需求的招聘顾问和猎头。它将用户明确授权的**猎头初访**通话转写、速记或零散笔记，整理为统一的结构化访谈记录，帮助后续人工复核、候选人意愿分析、推荐报告或其他合规的招聘流程使用。

它只做材料中的候选人陈述、经历、项目、求职动机、工作相关约束、顾问观察和待跟进问题的结构化整理；不评判真实性或证据质量，不对候选人作录用/淘汰判断，不读取任何智联系统、候选人库、邮件、聊天记录或未提供的材料。猎头初访、候选人沟通和正式面试是不同材料类型：正式面试记录属于第二批 B 的“面试记录结构化”，不能在本 Skill 中混作面试结论。

## 触发与最小输入

适用于“整理猎头访谈记录”“把初访转写变成纪要”“整理猎头速记”“提取候选人动机和待跟进项”等请求。用户需提供：

1. 经授权的猎头初访或深聊材料；
2. 候选人代称或匿名标识（非必需，但建议不使用完整姓名）；
3. 岗位或访谈目标（可选；没有时只按材料组织，不推断考察标准）；
4. 记录来源与角色，例如通话转写、猎头速记或顾问笔记；
5. 是否需要合并多轮访谈材料。

处理前只请求完成任务所必需的信息。不得要求或复述联系方式、证件、详细住址、账号凭据等无关个人信息。若授权范围不清、材料来源不明、文件无法读取或用户提供的是正式面试材料，停止处理相关个人信息并说明所需最小材料或适用 Skill。

## 工作流

1. **确认材料类型与范围**：标明每份材料是猎头初访转写、速记还是顾问笔记；无法确认时列为待验证，不假定其效力。
2. **提取可定位信息**：按“访谈议题—候选人陈述或记录事实—顾问观察—待跟进”拆分。转写的口误、残句或归属不清内容不得擅自修正为完整事实。
3. **按主题归档**：有岗位目标时，可按经历、项目、能力、求职动机、工作相关约束和风险/未知项归档；没有目标时只使用材料自身主题。
4. **保留材料差异**：并列展示不同轮次或不同记录者的陈述差异，不以顾问判断覆盖候选人陈述，也不把推测改写为已验证事实。
5. **列出待验证项**：标记材料缺失、前后冲突、陈述含糊和需要下一次沟通补充的问题；不自行选择“更合理”的版本。
6. **交付结构化记录**：按 `templates/structured-interview-record.md` 输出，清晰区分事实、顾问判断和待验证项。

## 输出契约

输出必须遵循共享护栏的三层标签：

- **事实**：使用“访谈记录提到”“候选人陈述”“顾问笔记写明”等表述，并注明对应材料来源或议题。
- **顾问判断**：仅可提出整理优先级或建议补充验证方向，必须说明依据和不确定性。
- **待验证项**：对缺失、冲突、归属不明或授权不清的内容提出最小核验问题，不补全。

默认交付：访谈元信息与材料范围、经历/项目/动机/约束记录、顾问观察、材料差异、待验证项和下一步建议。它不输出录用建议、候选人排名、真实性定论、法律/平台合规结论或对未提供材料的推断。

## 异常与衔接

- 多份材料互相矛盾时，逐项注明来源并保留冲突；不能合并为单一事实。
- 材料无岗位信息时，仍可做中性结构化，不能据此补造招聘标准。
- 用户要求分析候选人意愿或撰写客户推荐报告时，可将本 Skill 的交付物作为第二批 B 的候选人意愿分析/候选人推荐报告的可选输入，但不构成运行时依赖。
- 用户要求更新候选人流程、发送反馈、检索候选人或读取平台记录时，说明该请求不在本包范围，不模拟执行。
