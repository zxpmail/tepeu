# 智联招聘｜候选人意愿分析

## 目标与边界

本 Skill 面向猎头顾问和招聘推进人员。它只基于用户明确提供或明确授权的候选人沟通记录、初访记录或人工整理摘要，梳理候选人**在材料中已表达**的职业动机、岗位兴趣、关注事项、顾虑、时间安排和工作相关条件，并形成可由人工核验的下一步沟通建议。

“意愿”在本 Skill 中仅指当前材料所呈现的沟通状态，不等同于候选人的真实心理状态、最终入职决定或 Offer 接受概率。不得把候选人的沉默、语气、回复速度、表情、关系网络或未提供的流程信息解释为接受、拒绝或流失信号。

本 Skill 不读取智联平台消息、私信、邮件、社交关系或未提供的历史记录；不发送消息、自动联系候选人、更新候选人状态、进行候选人排序，亦不作录用、淘汰或继续推进决定。

## 适用请求与最小输入

适用于“梳理候选人当前关注点”“分析初访中已表达的顾虑”“整理需要确认的意愿问题”“比较多轮沟通中的表述变化”等请求。每次分析至少需要：

- 经授权的沟通材料或由用户整理的沟通摘要；
- 材料来源、用途与授权范围；
- 可定位的时间点、轮次或先后顺序；若缺失，必须标为“时间未知”；
- 如涉及某个岗位，提供已确认的岗位名称或岗位关键信息。

当前招聘阶段、候选人需要在何时确认的事项、已知薪酬/地点/到岗约束均为可选输入。默认不请求或复述联系方式、证件号码、精确住址、账号凭据、无关家庭信息等非必要个人信息。材料来源不明、授权不清、与当前目的无关或无法判断是否可处理时，停止处理相关个人内容，只说明所需的最小授权或材料；不得据此推断候选人态度。

## 执行方法

1. **确认材料范围。** 先说明本次使用的材料来源、时间范围、岗位和已知招聘阶段；不完整的信息写为“未提供”，不补全默认值。
2. **建立证据清单。** 提取候选人的直接陈述，并按职业动机、岗位兴趣、工作相关条件、关注事项、已表达顾虑、明确承诺或保留意见归类。每条都标注来源和时间/轮次；用户转述的候选人表述须标明“转述”，不能当作原始逐字记录。
3. **区分材料层级。** 候选人直接陈述列为“已表达事实”；招聘方或用户描述的外部情况列为“用户提供的观察”；由材料归纳出的推进阻力、确认顺序和沟通重点列为“顾问判断”。任何顾问判断必须写明其依据和不确定性。
4. **判断当前沟通状态。** 仅依据候选人明确陈述，使用“已明确表达愿意继续了解”“已明确表达存在待解决条件”“尚无法判断”这类事实性状态描述。若没有足够的直接陈述，必须输出“材料不足，无法判断”，不得给出意愿等级、分数或概率。
5. **处理冲突与缺口。** 不同时间或材料中的表述不一致时，按来源和时间并列保留，不选定任一版本为事实；指出需要由候选人确认的最小问题。较早陈述不能自动覆盖较晚陈述，反之亦然。
6. **提出人工可执行的下一步。** 只提供中性的核验问题、沟通主题、建议顺序与需要用户决定的节点。建议必须服务于澄清当前材料，不得伪装为联系候选人、施压推进或影响候选人决定的指令。

## 输出要求

默认按以下结构输出；未被材料支持的部分明确写“未提供”或“无法判断”：

1. **材料范围与处理前提**：列出材料来源、时间/轮次、授权状态、岗位及已知阶段。
2. **候选人已表达的事实**：用表格列出主题、候选人陈述或经注明的转述、来源/时间，以及尚未确认之处。
3. **当前材料呈现的沟通状态**：分别列出明确的积极表达、明确的待解决条件和未知项；不使用意愿分数、排序或接受概率。
4. **顾问判断与依据**：仅陈述材料支持的可能推进因素或阻力；每项同时提供证据、替代解释或不确定性。
5. **待验证项与下一步**：给出最小澄清问题、建议沟通主题及顺序、需由用户或业务方决定的事项。

全部输出必须区分“候选人已表达的事实 / 用户提供的观察 / 顾问判断 / 待验证项”。不得产生真实性结论，不得将材料之外的行为、偏好或关系写成候选人事实，也不得输出录用、淘汰或继续推进的决定性建议。

## 异常处理与衔接

- **只有简历或 JD，没有沟通材料：** 说明无法分析候选人当前意愿；可提供一份中性、面向岗位条件核验的沟通问题清单。
- **缺少来源、授权或时间：** 停止涉及个人内容的分析；仅请求最小必要的授权、来源或时间信息，不从缺失信息推断态度。
- **材料相互矛盾：** 并列展示各自来源与时间，并将冲突转为待验证问题；不选择任何一方作为最终结论。
- **用户要求读取平台会话、发送触达或更新流程：** 说明该请求不在本 Skill 范围内；如未来确需调用经授权的外部系统，应另行通过已确认的 Connector 能力处理，不模拟执行。

结构化初访记录可作为本 Skill 的输入；候选人推荐报告可以引用其输出，但两个能力不构成运行时依赖。
