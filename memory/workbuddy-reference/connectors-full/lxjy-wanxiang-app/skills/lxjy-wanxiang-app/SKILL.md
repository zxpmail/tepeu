# 梁溪教育万象应用连接器

## 适用场景

当用户要求查询或管理梁溪教育万象应用、项目与应用绑定、应用仓库、页面版本，或上传应用页面和资源文件时，使用本 Skill。

典型触发词：万象应用、应用列表、应用仓库、项目绑定、页面版本、上传页面、上传资源、访问链接、二维码。

## 身份与授权

- 调用前确认连接器可用，并调用 `who_am_i` 验证当前授权身份。
- MCP 请求由 WorkBuddy 的 OAuth 授权自动携带访问令牌；不要向用户索取账号密码或 OAuth Token。
- 连接未授权、身份验证失败或工具不可用时，说明具体问题并停止相关平台操作。
- 只操作当前授权用户有权访问的应用和项目。

## 工具使用

- 用 `list_available_applications` 按名称查找当前用户已有应用。
- 用 `list_project_context` 查找项目绑定；用 `resolve_project_binding` 和 `get_project_context` 核对指定项目的绑定、应用、仓库和页面信息。
- 用 `create_project_application` 创建并绑定应用；用 `bind_project_application` 绑定用户选定的已有应用。
- 用 `ensure_application_repository` 按业务用途复用或创建仓库。
- 用 `list_page_versions` 查询应用页面版本。
- 用户确认写入后，再执行创建、绑定、建仓或上传操作；不要因名称相似而自行选择目标应用。

## 文件上传与身份识别

1. 上传前取得待上传文件的文件名、大小和 SHA-256 摘要，并确认目标项目与应用绑定正确。
2. 调用 `prepare_application_upload` 申请单文件上传票据。该工具依据已授权的 OAuth 用户检查项目绑定、应用归属和相应权限。
3. 将文件以 multipart 方式提交到该工具返回的同环境上传地址，并在 `X-Upload-Ticket` 请求头中携带票据。
4. 上传接口使用服务端签名的短时票据识别用户，并核对票据绑定的项目、应用、文件类型、文件名、大小和 SHA-256。
5. 不把 OAuth 访问令牌传给上传脚本或上传接口；不将上传票据写入页面、持久文件或交付说明。
6. 票据无效或过期时，重新检查文件与目标后申请新票据。上传失败时根据服务端返回的原因处理，不要原样反复提交。

## 写入确认与结果说明

- 创建、绑定、建仓和上传会改变平台数据；执行前应向用户说明目标和影响，并取得明确确认。
- 成功后报告实际创建或更新的应用、仓库或页面，并使用工具返回的访问链接、版本信息或二维码。
- 不要把本地预览或上传成功表述成已验证页面业务接口。
