# DxC 历史文章知识库

内部调用 DxC CLI 时只使用 PATH 中的全局入口：`dxc <参数>`。本 Skill 的版本是 `0.3.24`，
安装流程必须已经验证 `dxc version --json`、本 Skill 集和该版本完全一致。正常任务不得通过 npm、
npx 或其他包执行器解析 DxC，也不得硬编码任何用户的可执行文件绝对路径。若 `dxc` 不在 PATH，或
CLI 报告官方 Skill 版本不一致，停止并请用户按安装说明重新安装同一指定版本；不在当前任务内联网
解析、切换版本或改用仓库源码。

DxC 的调用由本 Skill 给出。每次只直接执行当前 Skill 明确写出的一个 DxC 命令，不寻找或猜测替代命令。只把 CLI 上一次结构化结果中的 `workItemId` 或 `choiceId` 作为不可解释也不可编辑的字段直接交给下一次结构化调用；字段传递不得经过模型重新生成或自然语言转录。禁止手工复制、拼接、改写、截取、解码、重建、落盘、持久化或转存这些值，也不要求用户接触它们。

调用仍在运行时，`DXC_BROWSER_EVENT` 只表示需要立即承载当前页面，不表示命令失败或完成。等到进程退出并收到唯一的 `DXC_RESULT` 最终帧后，先把其中完整结构化结果作为当前事实保存，再向用户转述；不得用进度文案、浏览器地址或自己概括的字段替代最终工作项。

禁止用 Python、Shell、PowerShell 临时脚本、循环、管道、命令替换、后台任务、并发或定时器包装 DxC 命令。禁止调用 CLI help，禁止查看源码、日志、内部文件或解析返回值内部结构来推断下一步。没有明确的下一步时，停在这里，如实告诉用户当前还不能继续。

CLI 失败时，若当前 Skill 明确规定了 CLI 返回选项、用户选择后继续的分支，只按该分支等待并提交用户选择。
其余失败禁止再次调用、轮询、跳阶段、重新进入阶段或创建替代项目。只转述其中面向用户的 `message` 和唯一 `recovery` 所表达的安全方向，隐藏命令、内部标识、本地位置和诊断细节，然后停止；不得自行执行恢复动作或推测根因。

若宿主无法把完整结构化字段直接传给下一次调用，停止并说明交接能力不足；不得为了继续而手抄或重建引用。
状态目录权限被拒绝时，用户的自然语言同意不改变沙箱。只有宿主实际授予目标目录权限后才能继续；
不要反复在相同受限环境执行，也不要修改全局安全配置、放宽目录权限或搬迁文章。doctor 的工作目录检查不代表文章状态目录可写。

DxC 项目在质量审校通过且正文哈希仍匹配时，由工作流内核自动幂等记入本地 Knowledge；不需要用户额外触发本 Skill，也不等待微信公众号草稿。项目创建时自动召回的片段只作参考，不代表当前事实或逐字采用许可。

查看、导出和删除免费；检索、导入、编辑、采用和重建索引需要有效试用或订阅。收到 `DXC_BILLING_*` 时不改知识库或当前项目，只提供 CLI 返回的订阅恢复方向并停下。

导入外部历史文章前向用户说明：内容只在本机建立检索索引，返回给宿主的少量片段可能被宿主处理，历史全文不会上传。

- 导入：用户明确选择一个文件或目录后，执行一次 `dxc knowledge import --source <用户选择的位置> --json`。
- 检索：执行一次 `dxc knowledge search <用户的写作目标> --source history --json`，展示匹配结果供用户选择。
- 采用：用户明确选中一篇结果和当前文章后，执行一次 `dxc knowledge adopt --project <用户选定文章> --item <用户选定结果> --json`。
- 查看状态：执行一次 `dxc knowledge status --json`。
- 修复索引：自动收录回执为 `semantic: pending` 时，向用户说明正文和关键词索引已经保留；用户允许准备本地模型后，对已登记项目执行一次 `dxc knowledge reindex --project <项目总览返回的 projectId> --prepare-model --json`。不得从标题重建项目 ID。
- 删除：用户明确选中一篇检索结果后，执行一次 `dxc knowledge remove <用户选定结果> --json`。

不要把“自动收录 DxC 完成稿”扩大成扫描其他位置。不要拼多条导入命令、自动选择结果、替换检索方式或编排模型安装。第一次建立语义检索能力时，若 CLI 给出需要用户决定的选项，只展示选项并等待用户选择。检索结果过期或当前不能继续时，要求用户重新检索并重新选择。

导入或检索遇到本地语义模型不可用、CLI 返回需要用户选择的选项时，进入本受控分支。
只展示返回的选项；用户选定后，把该 `choiceId` 原样附在刚才的同一操作上，执行一次
`dxc knowledge import --source <原位置> --choice <所选 choiceId> --json` 或
`dxc knowledge search <原写作目标> --source history --choice <所选 choiceId> --json`。
保持原位置、目标及其他参数，不自行选关键词模式、不解析选项引用。再次需要选择就等待用户，
其他失败按公共停止规则处理；用户未选择时不得续接。
