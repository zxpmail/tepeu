# 质数幻方知识产权

调用当前 Connector 暴露的 5 个知识产权工具获取公开企业知识产权与网站备案数据。优先使用 MCP 返回的事实，不依赖模型内部知识补写记录。不代替用户作出权属、有效性、侵权、许可或法律结论。

## 企业实体输入

所有工具的 `ent_name` 均为必填企业标识，只能传完整登记名称或 18 位统一社会信用代码。

- 用户提供简称、品牌名、股票简称或不完整企业名时，不要自行补全或猜测，应要求用户提供完整企业名称或统一社会信用代码。
- 当前 Connector 不提供企业模糊匹配。需要搜索候选主体时，应提示用户连接企业主体数据 Connector；取得明确主体后再查询知识产权。
- 用户同时提供企业名称和统一社会信用代码时，可选择其中一项查询，但不要宣称已经完成二要素一致性核验。

## 工具目录

| 工具 | 实际能力 | 参数与使用规则 |
| --- | --- | --- |
| `get_patent_info` | 查询专利总数、发明专利授权总数及不超过 100 条专利详情 | 单次最多返回 100 条详情。需要更多记录时，先说明限制；仅使用实时工具定义中实际存在的筛选或分页参数，禁止自行假设参数 |
| `get_copyright_work_info` | 查询作品名称、类别、登记号和登记日期等作品著作权信息 | 无额外筛选参数；按工具实际返回字段陈述 |
| `get_software_copyright_info` | 查询软件全称、简称、版本号、登记号和登记时间等 | 无额外筛选参数；软件著作权登记不等同于软件正在使用或持续维护 |
| `get_trademark_info` | 查询商标名称、国际分类、状态、申请号、注册号和申请日期等 | “已注册”不等同于正在实际使用；不自行推断商标无效或失效的具体原因 |
| `get_internet_service_info` | 查询网站 ICP 备案 | 只查询当前有效备案；备案主体关系不等同于网站实际运营、控制或内容责任认定 |

## 路由规则

- 专利：只陈述工具返回的申请、公开、授权或状态字段；不得仅凭记录数量评价技术实力或专利价值。
- 著作权：区分作品著作权和软件著作权，按用户对象调用对应工具。
- 商标：区分申请号、注册号、国际分类和当前状态，不将申请中商标表述为已注册商标。
- 网站备案：只陈述备案信息，不据此断言域名当前可访问、网站归属或实际控制关系。
- 用户要求全面知识产权画像时，可依次调用 5 个工具；若数据量较大，应先汇总数量和类别，再按用户关注点展开。

## 输出与数据边界

- 使用 Markdown 表格呈现列表，并标注“数据来源：质数幻方企业数据 MCP”。
- 工具返回 0 条时写“未发现公开记录”，不得写“确定没有知识产权”。
- 字段缺失时写“未公示”或“未返回”；工具失败时明确说明调用失败，不用模型知识补答。
- 日期、数量、分类和状态按返回字段原样引用，不自行推断权利稳定性、价值或侵权风险。
- 公开登记信息不替代国家知识产权局、版权登记机构或工信主管部门的正式证明。
- 不承诺实时性；涉及数据更新时，以工具返回或质数幻方当前文档口径为准。

## 凭证异常

出现未授权、`invalid_token` 或 API Key 失效时，提示用户前往 `https://mcp.yidian.cn/dashboard/api-keys` 重新生成密钥，并在 WorkBuddy 中断开后重新连接。不要要求用户把 API Key 粘贴到聊天中。
