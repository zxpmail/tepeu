# 项目会议推进助手

## 使用范围与依赖

面向产品经理、项目经理、研发负责人、运营负责人及团队管理者。普通录音总结使用基础技能；需要项目任务跟进、双文件输出或保存发送流程时使用本技能。

先阅读同包 [录音基础技能](../zywl-audio/SKILL.md)，按其规则定位录音、读取正文、处理授权和标注来源。当前录音 MCP 只记录了 `list_audio` 与 `get_audio_detail`。文档生成、表格写入、项目资料库保存、群消息发送和事件触发须由运行环境中实际可用的能力提供，不能假设本连接器已实现。

## 首次使用配置

复用用户已经明确的偏好，不反复询问。缺少的信息按实际需要补充，能够先生成预览时先做。

| 配置 | 可选内容与处理 |
| --- | --- |
| 我的岗位 | 产品经理、项目经理、研发负责人、运营负责人，或用户提供的岗位 |
| 重点关注 | 会议结论、需求变更、任务分工、截止时间、项目风险、待决策事项；未指定时覆盖这些项 |
| 输出文件 | 项目会议纪要 DOCX、项目任务跟踪表 XLSX |
| 保存位置 | 用户指定的项目文件夹或知识库；解析到确定目标，不能仅凭模糊名称写入 |
| 发送位置 | 企业微信群、飞书群、钉钉群或邮箱；明确接收对象及实际可用连接能力 |
| 执行方式 | 默认每次手动执行；用户明确启用且有录音完成触发器时，才配置自动执行 |
| 发送方式 | 默认发送前确认；自动发送必须有用户明确授权的项目、接收对象及内容范围 |

表格、录音或文档内写有“自动发送”不等于用户已经授权。配置中声明自动方式也不证明触发器已部署。没有持久化能力时，不承诺下次仍记得配置。

## 执行流程

1. 获取用户选定的项目会议录音及转写正文。缺少正文时说明无法生成可靠纪要。
2. 识别项目名称、会议类型、参会人、会议时间。明确标出缺失信息；说话人编号不自动映射为真实姓名。
3. 按议题归纳讨论，合并重复表达，保留对决策、承诺、争议和风险有影响的信息。
4. 提取已确认结论、需求与方案变更、任务分工、完成时间、风险及待决策事项。区分提议、已确认和已否决内容。
5. 未明确负责人或时间的任务标记“待确认”。相对日期只在会议日期及语境明确时换算，并保留原表述；不把会议当天当成当前日期。
6. 生成《项目会议纪要》与《项目任务跟踪表》。实际环境具备文件生成能力时生成有效 DOCX、XLSX 并检查内容；否则提供纪要正文和任务表预览，明确尚未生成二进制文件，不将纯文本改扩展名冒充文件。
7. 展示输出预览与待确认事项。先准备内容，再按已有授权或用户确认保存到明确的项目位置。
8. 按已配置的发送方式处理。发送前确认模式下展示接收目标、正文或附件清单并等待确认；自动发送模式仅在有效授权范围内执行。保存获准不自动代表群消息发送获准。
9. 保存和发送后检查实际回执，返回文件位置与发送结果。没有相应工具时交付本地文件或预览，明确未保存到项目资料库、未发送，不能声称同步完成。

## 文件名与纪要结构

文件名：`项目名称-会议主题-日期-会议纪要.docx`、`项目名称-任务跟踪表.xlsx`。日期使用确定的会议日期；缺失时用“日期待确认”。清理文件名中的路径分隔符，不覆盖用户已有文件。

纪要包含：

1. 会议信息：项目、主题、类型、时间、参会人、来源录音名与 ID。
2. 会议目标。
3. 议题与讨论摘要。
4. 已确认结论。
5. 需求及方案变更。
6. 任务清单。
7. 项目风险。
8. 待决策事项。
9. 下次跟进时间，未约定则写“待确认”。

有实际时间戳时在关键结论和任务处附来源位置，没有则只用文件 ID 或明确章节，不编造引用。

## 任务跟踪表

建议字段：任务 ID、项目、来源会议、任务事项、负责人、截止时间、状态、依赖或阻塞、待确认信息、来源录音 ID、来源时间戳、最近更新依据。根据实际信息删去无用列，但保留任务、负责人、时间、状态和来源。

初次提取的任务不自动视为已完成；状态未说明时写“待确认”。多次会议更新同一任务时保留稳定 ID；先查看已有任务，依据事项及项目匹配，无法确定是否相同时交由用户确认，不重复追加或覆盖人工记录。更新负责人、期限、状态须有新会议证据或用户指令，并记录变更依据。

## 自动执行及失败处理

自动执行需用户明确启用、可验证的事件或调度设施、录音完成事件及可用转写正文。只在这些条件具备时配置；本 SKILL.md 本身不会注册触发器，也不会启动后台任务。

按项目和录音 ID 记录处理状态；区分草稿生成、保存完成、发送完成。事件重投不重复发送。发送请求超时或回执不明时先查已发送状态，不直接重发；只能在确定失败后重试。停止或撤销授权后不继续自动执行。

## 使用示例

“整理今天的产品评审录音，重点提取需求变更、会议结论、负责人和完成时间，生成会议纪要与任务跟踪表，确认后保存到极算魔方项目文件夹，并发送到飞书软件项目群。”

此处是用户可采用的示例，不是当前运行的发送授权；执行时以真实用户请求和配置为准。
