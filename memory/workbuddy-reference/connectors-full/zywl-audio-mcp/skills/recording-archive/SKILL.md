# 录音文件归档助手

## 使用范围

适用于录音较多、名称不清晰、需要按项目或客户归档，以及查找历史录音的场景。品牌统一使用“极算魔方AI”。

## 获取资料

先阅读同包 [录音基础技能](../zywl-audio/SKILL.md) 的连接、参数、分页、正文读取和来源规则。当前工程仅记录 `list_audio` 与 `get_audio_detail` 两个只读工具。按运行时 schema 调用，不能虚构重命名、标签或移动接口。

用户已给出时间或文件范围时直接使用；未给出时询问范围。按范围分页读取列表，按需读取正文。基于实际录音时间分类；无法取得正文时只能按标题作初步分类，并标注依据。不得用文件名关键词检索冒充正文检索。

## 整理流程

1. 获取范围内文件及可信元信息，记录未能读取的文件。
2. 根据名称、录音时间及正文主题，按用户选择的客户、项目或会议类型分类。客户或项目不明确的放入“待确认”，不猜测归属。
3. 识别含义不清、仅编号或无法反映内容的名称，基于可用正文提出更清楚的名称。无正文时不要凭空补充主题。
4. 未分类状态优先依据真实标签或目录数据；若后端未提供这些字段，只能标为“分类状态未知”，不能声称确定未分类。
5. 根据相同名称、相近时间、时长或正文重合识别疑似重复，并写明理由。相似不代表同一文件；除非有可靠文件标识或校验依据，不标记为确定重复。
6. 生成分类、目录、重命名及标签建议。目录可使用“客户/项目/年月/类型”，命名可使用“日期-项目-主题”，按用户习惯调整。缺失部分省略或标为待确认，不生成虚假日期和项目名。
7. 展示操作预览；用户确认具体清单后，且实际工具具备相应写入能力时，才执行重命名、标签或归档。用户要求“先不要修改”时只输出方案。默认不删除文件，疑似重复项保留。

## 默认输出

- 文件分类结果：文件 ID、原名称、时间、客户、项目、类型、分类依据。
- 建议归档目录。
- 建议重命名清单：文件 ID、原名称、新名称、理由、是否待确认。
- 建议标签。
- 未分类或分类状态未知的文件。
- 疑似重复文件及判断依据。
- 需要用户确认的操作：具体对象、修改前后内容及目标位置。

给出实际扫描范围、文件数与正文缺失情况。无法完成全量扫描时将结果标为部分结果。

## 执行与回执

先检查目标目录及名称冲突；不覆盖同名文件。确认后使用实际暴露的工具，只处理已批准的行。若现有接口只读，交付可操作的归档方案并说明尚未执行。

实际写入后读取回执或回查结果，分别报告成功、失败、未执行项。超时导致状态不明时先查询状态，不盲目重试写入。部分成功时保留成功结果，只对明确失败且可安全重试的项继续处理。

## 使用示例

- “整理我最近一个月的录音，按客户和项目分类”
- “找出名称不清晰的录音，并根据内容推荐新名称”
- “把本周的录音按会议、客户沟通和个人备忘分类”
- “搜索所有与‘新品上市’有关的录音，整理成一份文件清单”
- “检查录音库中可能重复或尚未分类的文件”
- “为最近30天的录音生成归档方案，先不要修改文件”
