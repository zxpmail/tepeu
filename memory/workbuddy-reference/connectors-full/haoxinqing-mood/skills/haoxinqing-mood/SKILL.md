# 好心情心理健康工具指南

本连接器提供心理健康相关工具，分三类：

- **情绪工具**（需用户身份）：记录情绪、查询今日记录与统计
- **量表工具**（公开）：心理测评量表列表与详情
- **冥想工具**（公开）：正念冥想场景推荐

## 情绪工具（需用户授权）

情绪工具操作当前授权用户的数据。若用户未完成授权连接，调用会返回 401，应引导用户先连接好心情账号。

### emotion_record — 记录情绪

将用户当前情绪写入其情绪日记。**写入类操作，调用前必须先与用户确认情绪类型与强度，不得未经确认直接记录。**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| emotionType | integer | 是 | 情绪类型：1开心 2平静 3难过 4焦虑 5恐惧 6惊讶 7生气 |
| intensity | integer | 是 | 情绪强度：1轻微 2一般 3中等 4强烈 5非常强烈 |
| remark | string | 否 | 备注说明 |

返回：`{"success": true, "message": "情绪记录成功"}`

当用户描述感受但未明确说强度时，先询问或按语义合理推断并向用户复述确认（如"有点焦虑"→ 4焦虑 + 2一般）。

### emotion_today — 今日情绪记录

查询用户今日的情绪记录列表（含类型、强度、备注、记录时间，按时间倒序）。无参数。用户问"今天记了什么情绪/心情"时使用。

### emotion_overview — 情绪概览

返回本周或本月的平均情绪得分、记录天数与趋势（trendType：1上升 2下降 3持平）。用户想了解整体情绪状态时使用。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| statType | integer | 否 | 统计周期：1本周（默认）2本月 |

### emotion_trend — 情绪趋势

按日期返回本周或本月每日情绪得分与情绪类型列表，用于分析情绪随时间的变化。参数同 emotion_overview。

### emotion_distribution — 情绪分布

按情绪类型统计本周或本月各类情绪出现次数与名称，用于分析情绪构成。参数同 emotion_overview。

统计类工具的选择：问"整体怎么样"用 overview；问"变化/走势"用 trend；问"哪类情绪多"用 distribution。

## 量表工具（公开）

心理测评量表查询，只读，无用户身份要求。

### scale_list — 量表列表

分页查询心理量表库。返回量表ID、名称、类别、推荐语、题目数量、是否多因子、价格等。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| categoryId | integer | 否 | 量表分类ID，-1或不传表示全部分类 |
| name | string | 否 | 量表名称关键词 |
| pn | integer | 否 | 页码，从1开始，默认1 |
| ps | integer | 否 | 每页条数，默认10 |

### scale_detail — 量表详情

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 量表ID（advisoryInquiryId），可通过 scale_list 获取 |

返回名称、类别、推荐语、注意事项、限时分钟数、题目数量、价格等。

推荐流程：先 scale_list 拿到候选 → 用户选定后 scale_detail 展示详情。**本连接器不提供量表作答/下单能力，测评需用户自行前往好心情平台完成，介绍时应如实说明。**

## 冥想工具（公开）

### meditation_scenes — 冥想场景

获取所有启用的冥想场景（含场景ID、名称、分类、视频/音频/封面地址与时长）。无参数。用户想冥想放松、需要推荐冥想内容时使用，返回后可直接把音频地址和时长呈现给用户挑选。

## 认证与错误处理

- 情绪类工具依赖用户授权（OAuth）。收到 401 或"未授权"错误时，提示用户在连接器设置中重新连接好心情账号，不要重试原调用。
- 参数错误返回 40000 级错误码与中文说明，修正参数后可重试。
- 统计周期参数 statType 仅支持 1（本周）或 2（本月）。
- 用户未记录过情绪时统计类工具可能返回空数据，应如实告知"暂无记录"，可顺带引导用 emotion_record 补记。

## 确认规则（高风险操作）

- emotion_record 是唯一写入类工具：调用前必须向用户复述"情绪类型 + 强度"并获确认。
- 其余工具均为只读查询，可直接调用。
