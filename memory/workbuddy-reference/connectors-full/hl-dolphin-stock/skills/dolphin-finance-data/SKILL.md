# 海豚金融数据查询

当用户需要查询 A 股的行情、估值、财报、资金、技术指标等数据时，按以下步骤执行：

1. **判断标的是否为 A 股。** 本工具仅支持 A 股个股、板块、指数和 A 股整体市场。美股、港股、外汇、期货、基金、数字货币等非 A 股标的一律不要调用本工具，直接告知用户不支持。
2. **把用户问题整理成一句自包含的 Query。** Query 中必须带上股票名称（或代码）、指标名称和时间描述，不要依赖上下文省略。例如用户先问"贵州茅台的净利润"，再问"那 ROE 呢"，第二次调用的 Query 应写成"贵州茅台的ROE"。
3. **调用 `AiFetchDataTool`，参数只有一个 `Query`。** 不需要预先解析实体、指标或日期，工具内部会自动识别。
4. **按需拆分多次调用。** 一次 Query 建议聚焦 1～2 只股票、少量指标。对比多只股票或跨多类指标（如同时要财报、行情、资金）时，拆成多次调用，每个子 Query 都自带股票名称和时间。
5. **根据返回结果作答。** 返回为按行组织的数据，每行包含股票名称、业务功能、日期或报告期、指标名称与指标值。作答时保留数据中的日期或报告期，不要自行推算或改写数值。

## 时间表达规范

- 实时数据不写时间或写"当前/最新"，如"贵州茅台最新价和市盈率"。
- 历史某天写具体日期，如"贵州茅台2025年6月30日的收盘价"。
- 财报数据写年份加报告期，如"2024年年报"、"2025年中报"、"2025年三季报"、"2025年一季度"；只写年份（如"2025年营业收入"）默认为该年年报。
- 多期对比写清全部期数，如"2023年和2024年净利润"、"近3年净利润"、"近8个季度营业收入"、"2025年各季度净利润"。
- 财务指标与实时行情可以在一个 Query 里同时出现，如"比较贵州茅台和宁德时代2025年营业收入、净利润、ROE和当前市盈率"。

## 能力覆盖

- **个股**：实时行情、K 线历史、估值（PE/PB/PS/PEG）、融资融券、主力资金、技术指标（MA/MACD/KDJ/RSI/BOLL）、支撑压力、筹码、财报四表与主要指标、龙虎榜、大宗交易、股东人数、十大股东。
- **板块与指数**：实时行情、K 线历史、热点板块、板块或指数内热点股票、热点板块成分股。
- **市场**：大盘行情、市场资金流向、涨跌分布、热点板块。

## 典型问题

- 贵州茅台最新价和市盈率
- 比较贵州茅台和宁德时代2025年营业收入、净利润和ROE
- 比亚迪近5年净利润
- 宁德时代2025年三季报的营业收入同比增速
- 今天大盘涨跌分布和主力资金流向

## 注意事项

- 工具返回"暂无数据"或空结果时，如实告知用户该期或该指标暂无数据，不要编造。
- 涉及尚未披露的报告期（如当年年报），改用该年已披露的最近一期。
- 返回的数值已带单位（如"亿"、"%"），作答时原样保留。
