# Wimo Gen

通过 Wimo MCP 完成图片和视频创作；当前不支持独立音频生成。

## 自动连接与执行

使用当前客户端提供的原生 Wimo MCP 工具。安装或缺少连接时先读 [安装与连接](references/connection.md)，由 Agent 根据实际客户端完成安装和授权；不要求用户手动运行命令或填写密钥。

### 连接状态

- `creator_*` 工具不可见时，先按客户端认证和工具发现状态排查，不据此判断能力缺失。
- 自动认证失败时，优先使用客户端提供的重新授权或手动授权入口；认证未完成前停止依赖操作。
- 只有认证成功、工具已刷新且客户端明确返回 unknown tool/server，才能报告能力缺失；不重复安装、猜测工具名或切换服务。

- 服务地址以完整包的 `mcp.json` 为准；Codex 使用包内 `agents/openai.yaml` 的原生依赖声明，两者在打包时校验一致。安装后由客户端管理 OAuth。
- Codex 安装须保留完整技能目录（包括 `agents/`），不提前执行 `codex mcp add`。技能安装后，在原会话下一条用户消息明确使用 `$wimo-gen`，由客户端触发依赖安装；不能把当前轮阅读文件当成依赖已安装。
- Codex 本轮刚注册后仍无模型工具时，先通过 `codex mcp list` 确认服务已注册、地址正确、OAuth 已登录，再按连接说明的工具列表延迟流程处理；不能仅因列表缺失就认定地址不一致、删除配置或重复安装。若客户端已注册同名服务且地址正确、OAuth 已登录：告知用户这是会话级工具列表缓存，推荐**新开会话**后使用 `$wimo-gen` 引用。
- 文中的 `creator_*` 是服务端工具名，通过客户端实际暴露的对应工具调用。
- 缺失工具按用户意图判断：普通图片／视频生成依赖 Flow 工具，仅画布／节点请求依赖画布工具。

## 执行约束

- 工具 schema 与后端返回是唯一合同。能力、配置或必需字段缺失时说明原因，停止依赖操作；不猜模型、参数或产物，不切换服务或低层接口。
- 复用用户指定或当前会话已有的对应模式项目；指定项目不可用时报告，不擅自替换。无项目时才创建，用户明确要求新建除外。
- Flow 未要求批量时只提交一个逻辑任务；画布仅执行用户要求的节点依赖链。沿用用户明确的数量与授权，仅澄清影响结果或费用的未定选择。

## 能力边界

- 当前 MCP 工具集是**生成**（文生图、图生图、文生视频、图生视频、参考帧生成）和**画布编排**工具，**不包含**图片编辑（改字、加文字、滤镜、裁剪、合成等）、视频剪辑（拼接、转场、特效等）、本地文件批量处理等能力。用户提出这类需求时，明确说明能力范围并建议改用 Flow Web 端或画布节点逐步操作。
- 本技能不是通用图片/视频处理工具；超出生成和画布编排范围的需求应诚实告知不可用，不编造方案或用低层 API 拼凑。

## 按意图执行

- **画布编排或节点操作**：先读 [画布工作流](references/canvas-workflow.md)，支持文本、图片、视频节点的创建、修改、参考绑定与逐步生成。普通图片／视频生成沿用 Flow；用户明确要求画布或节点时才进入画布流程。
- **Flow 生成**：先读 [模型与参数](references/model-and-operation.md)、[工作流](references/workflow.md)；需要整理提示词、批量或参考素材时再读 [创作描述](references/prompt-patterns.md)。使用 `creator_list_models` 发现模型，`creator_get_project` / `creator_create_project` 准备项目，`creator_create_generation_task` 提交。
- **素材上传**：调用 `creator_upload_media` 获取真实 `media_id`，再按模型槽位传入 `source_media_id` / `source_media_ids`。该工具支持两种输入：**公网 HTTPS URL**（`source_url` 参数）或 **base64 文件数据**（`file_data` + `filename` + `mime_type` 参数），二者选一。用户提供本地文件时，Agent 可根据文件大小读取后以 base64 编码直接上传，无需用户先转为公网 URL。后端接口本身接受任何来源的 multipart 文件数据。用户明确要求保存到已有 Flow 项目时可传 `project_id`。
- **查询任务或产物**：画布任务使用 `creator_query_task`，产物用 `creator_get_node`；Flow 读 [工作流](references/workflow.md) 中的查询与展示规则，使用 `creator_query_task` / `creator_get_history`。不创建项目或发起生成；缺少查询标识时只补齐所需信息。
- **项目查询**：画布用 `creator_get_canvas`；Flow 按需使用 `creator_list_projects` / `creator_get_project`，仅返回与请求相关的项目。
- **连接检查**：仅在用户要求自检或需排查连接时调用 `creator_check_token`，成功后简短告知连接可用，不展示其返回的项目列表。
- **星币不足**：仅在返回 `code=INSUFFICIENT_BALANCE` 时按工作流恢复规则处理，不自动重发。

## 输出与隐私

- 创作完成、部分成功或结束等待时，使用本次真实 project_id 调用 `creator_get_project_link`，在最终回复附上可点击的 Markdown 项目链接，标签用“查看项目”；多个项目分别提供。项目查询结果也附对应链接，连接自检不展示项目链接。仅使用工具返回的 `project_url`，不从 MCP 地址或项目 ID 拼接；工具或字段缺失时保留已取得的产物和状态，并说明项目链接暂不可用，不重新生成。
- 默认只展示产物、项目链接、必要状态与需用户处理的下一步。无需复述提示词、参数清单、工具调用过程或重复播报未变化的状态。
- `project_id`、`node_id`、`task_id`、`media_id` 仅在用户要求、后续查询或素材复用确有需要时提供；不展示 `node_revision`、`client_mutation_id`、`request_id`、原始请求/响应、内部接口或堆栈。
- 不索取或回显 API Key、token、Cookie、授权头与其它认证凭据。默认由客户端发起 OAuth 连接或重新授权，用户只参与浏览器授权；不让用户处理密钥创建、轮换或替换。
- 只向生成工具传入完成创作所需的描述和素材，不夹带无关对话、账号资料或本地路径。恢复操作所需参数仅保留在当前会话中，不另存日志或文件。
- 错误只提取与本次操作相关、可行动且不含敏感信息的原因；不整段转发后端 `error` 或自检结果。原因缺失则说明无法确认，不编造。
- 项目、产物和充值链接仅用后端实际返回的对应 URL，不改写或拼接。可用授权链接用于展示，但不额外展开其中的签名、查询参数或存储信息；含账号 API Key、OAuth token 等认证凭据的链接不回显，并说明无法安全展示。
