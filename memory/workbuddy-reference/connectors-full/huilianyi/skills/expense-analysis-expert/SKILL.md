# 费用分析专家

## 何时使用

用户要求：分析费用趋势、部门/项目费用构成、找出异常或超支项、对比预算执行情况时，调用本连接器。

## 技能与工具

| 技能 | 工具名 | 用途 | 关键参数 | 写操作 |
| --- | --- | --- | --- | --- |
| 费用分析 | `expense-analysis` | 费用数据统计与分析 | 统计维度（时间/部门/项目/类别）、时间范围、分析口径 | 否 |

> 参数名以 MCP Server 实际 JSON Schema 为准。

## 调用约定

- 分析前先与用户对齐三要素：**时间范围、统计维度、费用口径**（申请金额 / 报销金额 / 已支付），口径不同结论差异大。
- 时间范围用绝对区间（`YYYY-MM-DD`）；"本季度"等相对时间先换算并说明。
- 返回数据后先给结论（总量、环比/同比、TOP 构成），再给明细；数字保留合理精度并注明币种。
- 数据点不足以支撑趋势结论时（如只有一个月数据），如实说明，不要强行解读。
- 涉及他人费用数据时注意权限：接口无权限返回时直接告知，不要反复尝试。

## 错误与恢复

| 现象 | 处理 |
| --- | --- |
| 401 / 授权失效 | 引导用户在连接器页重新「连接」 |
| 参数校验失败 | 按错误信息中的字段名与用户确认后重试 |
| 超时（>30s） | 缩小时间范围或维度后重试一次，仍失败则告知稍后再试 |
| 空数据 | 复述查询条件，确认是否口径或范围设置问题 |

## 认证前置

使用 MCP 自带 OAuth。首次使用需在连接器页点击「连接」完成汇联易登录。
