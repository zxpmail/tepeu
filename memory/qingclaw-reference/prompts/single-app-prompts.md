## 商机管理

帮我搭建一个轻流「商机管理」单应用，只创建一个表单。

字段结构：商机编号：自动编号；商机名称：文本，必填；关联客户：引用字段，引用「客户档案」应用，必填；负责人：成员，必填；商机阶段：单选，初步接触、需求确认、方案报价、商务谈判、赢单、输单；预计金额：金额；成交概率：百分比；预计成交日期：日期；商机来源：单选，官网、活动、转介绍、渠道、老客户、其他；关键联系人：文本；竞争对手：文本；下一步动作：多行文本；最近跟进日期：日期；商机状态：单选，推进中、已赢单、已输单、暂停；输单原因：多行文本。

布局要求：基础信息区一行 2 个字段，商机编号单独占一行，商机名称和关联客户同一行；销售信息区一行 3 个字段，负责人、商机阶段、预计金额优先展示；预测信息区一行 3 个字段，成交概率、预计成交日期、商机来源同一行；跟进说明单独占一行；移动端按单列展示。

视图设计：全部商机：表格视图；按钮：新增商机、导入商机。我的商机：表格视图，筛选负责人为当前用户；按钮：新增商机、更新阶段。商机看板：看板视图，按商机阶段分组；按钮：推进阶段、标记赢单、标记输单。预计成交日历：日历视图，按预计成交日期展示；按钮：新增商机。高金额商机：表格视图，筛选预计金额较高且推进中；按钮：更新跟进。

流程规则：商机进入方案报价阶段时提醒负责人补充报价信息；标记赢单后通知销售主管；标记输单时必须填写输单原因。
