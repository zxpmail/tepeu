## AutoGPT

地址：https://github.com/Significant-Gravitas/AutoGPT

它现在是一组专员。人用白话交代，专员准备草稿，人看过再决定发不发。满意以后，才把这次做法收成以后可以重复走的固定步骤。三年前那个「让模型自己一直干，直到它说做完」的试验，官方已经标成结束、不再维护。

可以对照着看的几点（尚未采纳）：

- 他们后来也不让模型自己宣布做完。
- 人要看见过程，不能只剩最后一句话。
- 能用什么、能花多少，由人事先圈定。
- 改和跑可以只对这一次、这一份内容点头。
- 密钥按文件位置拒绝，不靠模型认。
- 他们把「第一次有人看着做」和「以后重复做」分成两段。后一段要不要做，这里不定。
- 多个专员、应用市场、可视化编排、失败了换一条路接着跑，都只是他们的做法，这里不采用。

## caveman

地址：https://github.com/JuliusBrussee/caveman

它是让编程助手少说、少读，用来省字数。不是一套可以拿来做界面的东西。

和屏幕沾边的只有两块，也都不是现成页面：

- 浏览器插件是一个开关，在发给现成聊天网站的话前面加一句「回答短一点」。
- 「看网页」是把别人的页面压短，再交给模型读。

同名的聊天组件不在这个仓库里，只是一个普通对话窗。要不要用它做界面，这里不定。

## Stable Diffusion web UI

地址：https://github.com/AUTOMATIC1111/stable-diffusion-webui

这是一个在自己电脑上画图的网页。人写一段话，它画出图；也可以在已有的图上改、补一块、把图放大。页面用 Gradio 做。打开方式是在本机跑一个脚本，然后用浏览器看。

可以对照着看的几点（尚未采纳）：

- 它有真正的页面：进度、可以中途停下、参数可以改、结果能再拖回去看当时用了什么说法。
- 生成这张图时用的说法，会写进图片自己里面。以后把图拖回页面，能把当时的说法还原出来。
- 社区可以往页面里加扩展。要不要学这种「事后再加能力」，这里不定。
- 页面上可以跑任意代码，但必须单独打开一个开关才允许。
- 它是画图工具，不是交代任务、点头、记账、判断做完的那一套。要不要拿它的页面当以后的界面，这里不定。

## shadcn/ui

地址：https://github.com/shadcn-ui/ui

这是一套做网页界面用的零件，比如按钮、输入框、对话框。官方说明写得很明白：它不是装上就能用的整包零件库，而是把零件的源码交到你自己的项目里，你再改成自己的样子。文档在 https://ui.shadcn.com/docs 。

可以对照着看的几点（尚未采纳）：

- 零件的代码是敞开的，要改按钮就直接改那份代码，不用在外面套一层。
- 各个零件的用法比较整齐，方便人和模型读。
- 用命令把选中的零件取进项目，不是一次装进一整套。
- 默认样子已经配好，零件之间比较齐。
- 这一轮没有网页。要不要以后用它做界面，这里不定。

## Open WebUI

地址：https://github.com/open-webui/open-webui

这是一个自己架的聊天站。浏览器打开就能和模型说话，可以完全放在自己的机器上。模型可以接本机的 Ollama，也可以接各种兼容接口。文档在 https://docs.openwebui.com/ 。

可以对照着看的几点（尚未采纳）：

- 它有一整面聊天页：能看模型正在列清单、做着做着能排队下一句、手机上也能用。
- 能接工具、技能，也能让模型在聊天里开终端、改文件。能力可以事后再加。
- 它会记住你以前说过的事，带到下一轮聊天。这和「记忆不能拿来当做完的证据」不是同一件事，这里不定要不要学。
- 插件说明里提到可以做批准。具体怎么点头，这份公开说明没有展开。
- 画图可以转给本机的 Stable Diffusion web UI。那是接出去，不是它自己的账。
- 许可证不是随便复制整站就行，还要求保留「Open WebUI」这个名字。细节在仓库的 LICENSE。
- 这一轮没有网页。要不要以后拿它当界面，这里不定。

## Firecrawl

地址：https://github.com/firecrawl/firecrawl

这是给程序用的上网接口。给它一个网址，它把网页收成干净的文字、表格或截图；也可以先搜索，再整站收集。公开说明把它叫做给智能体准备的网页上下文。云上有托管服务，也可以自己架。自己架的说明在 https://docs.firecrawl.dev/contributing/self-host 。

可以对照着看的几点（尚未采纳）：

- 交给模型的是整理过的网页，不是一整页杂乱的原文。
- 除了读，它还能在页面上点击、滚动、输入，然后再取内容。
- 可以接到智能体或 MCP。MCP 的服务在另一个仓库：https://github.com/firecrawl/firecrawl-mcp-server 。
- 主体许可证是 AGPL-3.0。要不要用，先看许可证，这里不定。
- 这一轮没有装上网的工具。要不要以后接它，这里不定。

## Axelor Open Platform

地址：https://github.com/axelor/axelor-open-platform

这是用 Java 做业务系统的框架。公开说明写的是：用来创建现代业务应用。文档在 https://docs.axelor.com/adk/latest/ 。开发指南按这些块来写：应用和模块、数据模型、视图、动作、数据导入、网上接口、网页客户端。

可以对照着看的几点（尚未采纳）：

- 业务按模块拆开。字段、画面、按钮上的动作分开写。
- 画面是框架生成的业务页，不是聊天窗，也不是画图页。
- 许可证是 AGPL-3.0。要不要用，先看许可证，这里不定。
- 这一轮没有网页。要不要以后用它做业务画面，这里不定。

可以对照着看的几点（尚未采纳）：

- 说法和片子都属于原来的作者。要用某条说法，先看那一条自己怎么写的。
- 用法说明是：复制说法，交给 Opus 5.5，让它做成一个网页文件，再自己录屏。

## prompts.chat

地址：https://github.com/f/prompts.chat

这是一份给人用的说法库。以前叫 Awesome ChatGPT Prompts。公开说明写的是：收集给聊天模型用的说法，ChatGPT、Claude、Gemini 等都能用。网站在 https://prompts.chat/prompts 。说法也可以自己架一套。

它和上一节不是同一类。上一节是各家产品内部写给模型的系统说明。这一份是人可以复制、改完再发给模型的说法。

可以对照着看的几点（尚未采纳）：

- 想看「人怎么把一件事说给模型」，来这里翻说法，不要把说法抄进本仓库。
- 网站上还有常驻的机器人和机器人小组：几个机器人互相交活。要不要学这种编法，这里不定。

## Generative AI for Beginners

## erupt-skill

地址：https://github.com/plinian/erupt-skill

这是给编程助手用的一份技能说明。公开说明写的是：用一句话生成一套数据管理后台，底下用的是 erupt 低代码框架（https://www.erupt.xyz）。说「做一个图书管理后台」，就能得到能跑的登录页、增删改查、搜索、导入导出和权限。模板是 Spring Boot 3.5，数据库用内嵌的 H2，不用先装 MySQL。没有本机 Java 时，技能会自己下载一套。许可证是 Apache-2.0。

可以对照着看的几点（尚未采纳）：

- 想看「一句话变出一套管理后台」怎么做，来这里看技能说明和模板，不要把技能原文抄进本仓库。
- 它生成的是业务管理页，和 Axelor 那一节同类，不是聊天窗。差别是：Axelor 是人手写模块的框架，这一份是让编程助手按技能把项目生成出来。
- 说明里写了示例登录名和密码。那是他们演示站的默认账号，不是我们的。
- 它要装进 Claude、Cursor 这类编程助手的技能目录里才会被用上。我们这一轮没有网页，也不靠技能临时加能力。要不要以后用，这里不定。
