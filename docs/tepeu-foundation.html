七个能力模块

Tepeu 装在你自己电脑上，只给你一个人用。打开终端打几行字，就已经在用了。要守住的两件事：说过什么，打开记录能核对；要调用一项能力，先问准不准。

01一页看懂

要守住的是记录，以及调用前的授权。库根 tepeu/：四层 + load。依赖只朝下。

02从上到下

依赖只朝下：被调用方不知道调用方。persist 不知道 session；session 调用 persist。session 记下你打进来的字，也记下现在闲着还是在跑。host 能看见各家，因为它负责开机把线插上。

host · load · commands
host：Spring Boot（无 Web），按 POM 加载实现，`/` 行交给 commands。load：注入、拼系统提示、登记斜杠。commands：斜杠命令表。
tepeu/run · loop / llm / execution
loop 读本子、出门做事、再写回本子。llm 网关统一调用，第一刀后面挂 fake。execution 动工作区。工具经 dispatch 调用。
tepeu/kernel · session / policy / dispatch
账 + 门。session 是一次对话的记录。policy 做授权。dispatch 按名字调用处理函数。
tepeu/persist · api + sqlite
Tepeu 自己的状态读写。第一刀 sqlite。host 的 POM 依赖哪个，就加载哪个，交给 load。
tepeu/types · identity / syscall
共用类型：谁、工作区、哪一次对话；一次调用的信封。

03各管什么

每个文件夹一句话：干什么。

session一次对话的记录
这次对话存下来的状态，打开库能对上。
里面有 说过什么、花了多少、现在闲着还是在跑（关掉程序还在）
还有 刚打进来还没领走的字；你批准/拒绝另记一本；给屏幕的通知
policy授权
这件事这次能不能做：可以、不行、先问你。
管 三种答复，以及「问过你、你批了、用过一次就作废」
dispatch调用分发
按名字调用处理函数：模型生成、读文件、写文件、创建进程。
管 登记能做哪些事、替别人叫出去。未装配授权则拒绝
persist父 POM
上面是接口，第一刀一份实现。host 的 POM 依赖哪个，就用哪个。
api 会话、审批这些 Tepeu 自己的状态读写
第一刀 sqlite
llm父 POM
网关统一调用。实现挂在网关后。
gateway 从记录裁出模型该看的，再交给后面的实现
第一刀 fake 挂在网关后。系统提示由 load 拼好再交给 gateway / loop
execution工作区
读文件、写文件、跑命令，只动工作区。
管 文件和进程，关在指定目录里。隔离程度如实报告
loop跑一轮
读本子 → 问大模型 → 用工具 → 再写下。
管 领走你打的字、跑有限的几步、判断做完了没有、闲着时压缩旧记录。工具经 dispatch
identity共用类型
谁、在哪个工作区、哪一次对话。
里面 Principal、Workspace、SessionId、调用上下文
syscall共用类型
一次具名操作的信封：叫什么、参数、结果、用量。
里面 名称、参数、返回值、用量、参数摘要
conformance测试套件
给各模块写的契约测试，换实现也能跑同一套断言。
管 测试代码，验证接口有没有被守住
commands斜杠表
名称 → 处理函数。不经模型、不经 dispatch。
第一刀 /help /approve /status /btw。/btw 看本子问一句，不写对话、不调工具
load装配
注入实现、拼系统提示、登记斜杠命令。
管 看见四层与 commands。把 host 加载的实现注入网关与 persist 口
host你看见的程序
Spring Boot（无 Web）。终端。
管 POM 依赖哪个实现，就加载哪个，交给 load。`/` 行交给 commands

04谁找谁

依赖只朝下。被调用方不知道调用方。persist 不知道 session；session 是调用方，要知道 persist。

跑起来

已定走法

走法是什么
依赖只朝下Maven、import、运行时调用都朝下。persist 不知道 session；session 调用 persist-api
具名操作经 dispatch.invoke模型生成与工作区 I/O 走这里。打开持久化、/approve 是宿主与审批写入
session、policy 使用已打开的访问口host 打开并负责生命周期
给大模型看的那一截，从 llm 裁依据是事件日志
人手动做过的，记在操作审计批准、拒绝等
「做完了」一处宣判，依据是事件日志单一判定点

05实际怎么走

打字和斜杠命令已经能用。其余见规划未决。

开机
host（Spring Boot）按 POM 加载 persist / llm 实现 → load 装配、拼系统提示、登记斜杠与「问大模型」「动文件/命令」→ 等你打字
你打字
字先放下 → loop 领走 → 看看本子 → 裁出模型该看的 → 出门问大模型 → 模型要动文件就再出一次门 → 写下结果 → 看本子判断做完了没有
对话进对话记录，花费进花费那本。系统提示由 load 拼好
你打斜杠
/help 列出命令 · /approve 你点头或拒绝 · /status 看本子上有哪些记录 · /btw 旁问一句（不写对话、不调工具）
你动手的结果记在操作审计。用量进花费那本
闲着时整理旧记录
没人打字的空隙，loop 压缩旧对话。经 dispatch，写事件日志。你用 /status 能对上
