## 3. 修订原则（保证完整性与一致性）

1. **契约单一权威**：证据词汇、guard 序、wrapper 顺序、服务名、事件名以修订版 05 为 SSOT，spec 引用之；
2. **跨进程解析规则**（P1-34 决策）：插件服务解析仅限宿主服务内 Ctx；跨服务一律 Port/REST/Bus，禁止 Ctx 跨进程注入；
3. **受保护级别统一**：normal/admin/protected 三级词汇；16 个受保护（15🔒+1🔐）；
4. **验收命令可执行**：-Dtest 统一通配或显式类名；新模块路径标注"待 S 阶段新建"；
5. **类名标注**：gnex2.0 源码实证类 / spring-ai 依赖类 / 设计态新命名 三类标注；
6. **红线不放松**：P0-a/P0-b/E/租户红线修订后只增强不削弱。
