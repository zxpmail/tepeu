# 分域总纲

七个域。域之间只经契约索引里的服务键调用。

| 域 | 模块 | 场景 |
|---|---|---|
| 身份 | idn-context、idn-grant | S-IDN01 至 03 |
| 应用 | app-registry、app-router | S-APP01 至 03 |
| 服务 | svc-catalog | S-SVC01 至 03 |
| 界面 | ui-schema、ui-shell | S-UI01 至 03 |
| 数据 | dat-source、dat-entity、dat-query | S-DAT01 至 04 |
| 语义 | sem-package、sem-assemble | S-SEM01 至 03 |
| 应用包 | pkg-install | S-PKG01 至 03 |

桥接不是第八个业务域，它是所有域调用 gnex 的唯一出口。
