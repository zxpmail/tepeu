# 与 gnex3 的对照

依据审计修订版插件目录 L4 与接口关系。结论是消费、不重建。

| gnex 能力 | 基座态度 | 原因 |
|---|---|---|
| ent-tenant 硬过滤 | 消费令牌结果，本库另做行级安全 | 业务表不在 gnex 会话库 |
| ent-auth | 消费核验 | 第二套登录会不同步停用 |
| ent-org | 只读可选 | 应用角色仍要单建 |
| ent-audit | 投递 | 失败用外发队列 |
| approval | 已发布组装必须核对 | 不自建审批流 |
| credentials | 只存引用 | 清单不出现密钥 |
| agentLoop、工具管线、模型、沙箱、记忆、完成门 | 不实现 | 属于运行时。基座只注册五个业务工具 |
| client-kernel | 不复用其页面 | 业务外壳单独做，避免会话调试和业务单据混在一个信息架构里 |
| Ctx 跨进程注入 | 禁止 | gnex 接口关系已规定跨进程走端口 |

缺口：gnex 企业规格里的具体 URL 仍可能调整。桥接把 URL 放配置。平台管理员看令牌 `roles` 是否包含配置的角色名，不要求核验响应另给一个布尔字段。没有该角色就没有人是平台管理员，这是收紧，不是默认放行。
