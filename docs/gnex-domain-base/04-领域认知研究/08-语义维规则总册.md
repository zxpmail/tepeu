# 语义规则

| 编号 | 规则 | 可测试断言 |
|---|---|---|
| RSEM-01 | 顶层只允许五个段 | 多一个键则 RC-SEMANTIC-UNKNOWN |
| RSEM-02 | 动作只有四种 | approve 被拒绝 |
| RSEM-03 | 组装不能删字段 | dropField 校验失败 |
| RSEM-04 | 约束表达式与行策略同一套运算 | 出现函数调用则失败 |
| RUI-01 | 区块只有六种 | kanban 失败 |
| RUI-02 | 页面不得含脚本键 | 含 script 失败 |
| RDAT-01 | 不接受任意 SQL | RC-DIRECT-SQL |
| RDAT-02 | 跨源超过上限拒绝 | 第二源零调用 |
| RIDN-01 | 权限点三段 | 单段 422 |
| RAPP-01 | 菜单等于已发布路由 | 未发布路径不出现在菜单 |
