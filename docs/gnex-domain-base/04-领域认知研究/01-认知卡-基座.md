# 认知卡

## C-IDN-01 没有令牌就没有租户

- 判断：不能为了演示给一个默认租户。
- 场景：S-IDN01。
- 输入：请求头。
- 输出：上下文或拒绝。
- 规则：声明缺一不可。
- 错误做法：内网地址免登录。
- 验收：ACC-IDN-CTX-01。
- 出处：gnex 租户规格 fail-closed。

## C-APP-01 退役是终点

- 判断：已退役应用不能靠发布接口复活。
- 场景：S-APP03。
- 输入：目标状态。
- 输出：新状态或 RC-APP-STATE。
- 规则：只允许总体设计里的迁移。
- 错误做法：直接改数据库状态列。
- 验收：ACC-APP-03。
- 出处：D-013 之外的状态机，见总体设计。

## C-DAT-01 租户条件不可关

- 判断：调用方的过滤条件是附加的，不能替换租户条件。
- 场景：S-DAT03。
- 输入：用户过滤、权限、令牌租户。
- 输出：参数化查询。
- 规则：三段 AND，租户在最外层。
- 错误做法：提供 skipTenant 参数。
- 验收：ACC-Q-04。
- 出处：NFR-01。

## C-SEM-01 生产变更是单据不是提示词

- 判断：模型输出的文字不能直接变成页面。
- 场景：S-SEM02、S-SEM03。
- 输入：结构化差异。
- 输出：事务状态。
- 规则：已发布必须有核对通过的审批号。
- 错误做法：把模型回复写入页面表。
- 验收：ACC-AS-02。
- 出处：D-007。

## C-PKG-01 装到一半比没装更糟

- 判断：失败要回到安装前。
- 场景：S-PKG02。
- 输入：清单。
- 输出：成功或已回滚。
- 规则：元数据和托管建表同一事务。
- 错误做法：先发布菜单再补表。
- 验收：ACC-PKG-02。
- 出处：安装与恢复设计。
