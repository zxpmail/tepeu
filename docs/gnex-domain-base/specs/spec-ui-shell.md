# spec-ui-shell

> 来源：FR-UI-02、FR-UI-03、NFR-07
> 模块 ID：ui-shell｜能力域：界面｜保护级别：standard｜宿主：daf-shell｜实现状态：可开发

## §1 业务目标

业务用户需要一个稳定的外壳：当前租户、应用切换、菜单、无权限和停用说明。外壳不决定字段怎么排，那是页面模式的事。首版官方渲染器把六种区块画出来。对应 FR-UI-03、FR-UI-02、NFR-07。

## §2 需求映射与选型

| 维度 | 内容 |
|---|---|
| 需求映射 | FR-UI-03、FR-UI-02、FR-UI-06、NFR-07 |
| 对标借鉴 | 中后台外壳与内容分离。技术栈按 D-009 |
| 技术选型 | 选 React 18 + Vite 6 官方渲染器。备选是服务端渲染整页 HTML。不选的反例：区块交互（筛选、分页）每次整页刷新，和实体查询的分页参数对不上，智能体也难以只替换一块。复决：若企业浏览器不允许运行模块脚本，再增加无脚本的只读渲染，交互能力降级为链接翻页 |
| 改造要点 | 外壳只调 GET shell 与 GET page。渲染器按 type 分发到六个组件。文案中文 |

## §3 接口契约

### 3.1 提供服务

| 服务键 | 方法签名 | 语义 |
|---|---|---|
| ui.shell | `ShellModel load(String appKey)` | 聚合应用名、状态、菜单、权限点 |

浏览器不调用 Java 接口，调用 GET /apps/{appKey}/shell。

### 3.2 REST

GET /api/daf/v1/apps/{appKey}/shell。响应：`name`、`state`、`menu`、`permissions`。

### 3.3 事件

无。

### 3.4 消费依赖

| 服务键 | 必选/可选 | 用途 | 缺失时降级 |
|---|---|---|---|
| app.router | 必选 | 菜单 | 接口错误则外壳显示错误页，不显示空菜单冒充成功 |
| idn.grant | 必选 | 权限点 | 同上 |
| ui.schema | 必选 | 点菜单后取页面 | 422 时显示「页面无法显示」和 traceId |

## §4 数据模型

无新表。ShellModel 是读模型。

## §5 实现思路

前端路由：`/a/:appKey/*`。进入时请求 shell。state 为 SUSPENDED 显示停用说明，不请求页面。403 显示无权限。网络失败显示重试。

六个组件：表格（分页参数 page、pageSize）、表单（提交 create 或 update）、详情、筛选条（改写查询 filter）、统计卡（只读计数）、空态（rows 为空时由表格切换，不单独配数据）。

组件内不写死实体 URL，URL 由实体键拼出。不得出现连接串输入框。

## §6 边界

- ✅ 所有可见固定文案用中文。
- ❌ 禁止外壳直接请求外接数据库。
- ❌ 解耦红线：外壳不嵌入 gnex 会话调试界面。需要找智能体时只放一个链接，地址来自配置 `daf.shell.agent-console-url`，默认可空。空则不显示入口。

## §7 装配与配置

| 配置键 | 默认 | 说明 |
|---|---|---|
| daf.shell.agent-console-url | 空 | 空则隐藏 |
| daf.shell.api-base | /api/daf/v1 | 外壳请求前缀 |

### 运行命令

```bash
npm test -- --run src/shell
```

工作目录为 `daf-shell`。前端测试用项目已有的测试运行器；若仓库尚未初始化该包，本命令作为该包的验收命令，不在其他包里假跑。

## §9 影响域

外壳故障不影响 API 和其他租户。错误的渲染不得把 403 画成空表。
