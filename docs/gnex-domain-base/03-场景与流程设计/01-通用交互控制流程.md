# 通用交互控制流程

各场景册只写差异，公共顺序以本文件为准。

## 主路径

1. 外壳或工具携带令牌。
2. 过滤器核验。失败则结束，文案见字面量库。
3. 解析应用键。应用不存在按 404。状态不允许按场景册。
4. 计算权限。拒绝则结束。
5. 执行读或写。写之后投递审计，失败进外发队列。
6. 返回错误体或结果。错误体不带栈和 SQL。

## 四条输入约束

| 策略 | 做法 |
|---|---|
| 令牌 | 缺则拒绝，不默认租户 |
| 租户 | 路径或正文里的租户必须与令牌一致，否则拒绝且不返回对象 |
| 结构 | JSON 未知键在语义包和页面模式上拒绝 |
| 规模 | 分页和跨源超过上限即拒绝，不改成慢查询 |

## 降级

| 条件 | 行为 |
|---|---|
| 数据源或业务服务 DOWN | 返回 RC-SOURCE-DOWN，不返回空列表冒充成功 |
| 审计投递失败 | 业务事务可以已经提交，外发队列必须有行 |
| 审批服务不可用 | 草稿仍可落地；已发布变更保持未落地 |
| 基座进程停止 | gnex 内不调用基座的循环继续 |
