# 场景完备性

从五方面核对 22 个场景是否够首版，不把行业流程算进来。

| 方面 | 覆盖 | 缺口 |
|---|---|---|
| 标准路径 | 进入、授权、打开页面、查询、安装 | 无 |
| 角色 | 平台管理员、应用管理员、业务用户、智能体 | 不设「匿名访客」。公开页面会打穿租户，明确不做 |
| 生命周期 | 草稿、发布、停用、退役、安装、升级、回滚 | 卸载物理删表不做。退役代替删除 |
| 失败 | 无令牌、越权、停用、源 DOWN、超限、审批缺失、跳版 | 无 |
| 数据消费 | 托管与外接、单源与受控跨源 | 分析指标不做，见调研取舍 |

结论：首版场景闭集足够开工。新增场景必须先改总纲再改规格。
