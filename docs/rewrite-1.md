# Tepeu 管控内核规范

**状态**：2026-09-30 起。人已确认的规则。旧规划 [`rewrite-0.md`](./rewrite-0.md) 保留不续。第一刀代码已归档到 `legacy/first-knife/`，只读，不在旧账本和授权上补。  
**定位**：本文是 **Agent OS 管控内核规范**（静态能力型：内核口 + 可卸能力；覆盖安全、权限、调用、审批、审计、费用、完成判定、装载与记忆边界）。**不是**完整 Agent OS。缺完整任务/进程模型、调度、持久化与恢复、沙箱实现细节、组件 ABI、多租户、部署升级、可观测与测试套件等——那些另文补，不假装已有。  
**参照切法**：`C:\app-platform`（能力可裁；tepeu 自己是一整套，不是挂进 app-platform 的一块）。  
**问题**：屏幕只给最后一句；程序把「模型不再要工具」当成一轮结束。人与程序都没有掌控。

---

## 1. 一句话

可卸能力在运行前选好、焊进程序；内核口不可卸。没装上的能力，程序里就没有。模型不能自己长出新能力。做成没有，由常驻判定口按本轮平台证物判定，不由模型嘴里说。

---

## 2. 内核口与能力件

### 2.1 两类东西（勿混称）

| 种类 | 含义 | 装不装 |
|------|------|--------|
| **内核口** | 管控闭环必需：薄底、调用门、跑一轮（含装载）、判定做成 | 不可卸 |
| **能力件** | 人可单独决定装或不装的能力 | 可卸；没装则程序里没有 |

下文「组件清单」含两类；说「可卸」只指能力件。

### 2.2 何时定死

能力件在运行前一次定死：做成已选好的程序，启动后无再装配入口。固件式：安全优先，牺牲热插拔。

### 2.3 清单

| 名称 | 种类 | 干什么 |
|------|------|--------|
| 薄底 | 内核口 | 谁、范围、这一件、步骤账（含四种拒绝） |
| 调用门 | 内核口 | 未装能力拦住；**范围检查**；停认；点头/费用等前置 |
| 跑一轮 | 内核口 | 固定顺序串流程（见 §2.5）；含装载；不二次鉴权 |
| 判定做成 | 内核口 | 判定口常驻；策略可换，口不能卸 |
| 问模型 | 能力件 | 发已装好的请求（不决定装什么） |
| 人点头 | 能力件 | 需批准的事等人点头 |
| 费用 | 能力件 | 问模型额度；**问模型的硬前置** |
| 记忆 | 能力件 | 跨对话召回；只经装载进模型可见；不作判定证物 |
| 读东西 | 能力件 | 读允许范围内内容（默认不需点头） |
| 写东西 | 能力件 | 改允许范围内内容（**默认需点头**） |
| 跑命令 | 能力件 | 范围内起进程（**默认需点头**） |

**薄底**：「谁」= 操作的这个人。「范围」= 这次允许碰到的地方（表达另文；**强制在调用门**：出界=程序拦住）。换人或换范围，旧事实不带过来。「这一件」记在薄底，不是单独能力件。

**步骤账**：挂在一个薄底实例上（现行：一个进程一个默认薄底实例，即「本会话」；多会话另文）。审计全记；展示可分级。步骤账 ≠ 记忆。每条记录带写入者。每个字段只有一个写入者。同一时刻只允许一个写入者追加。跑一轮只编排，不写账。

| 字段 | 唯一写入者 | 只读 |
|------|------------|------|
| 待补全、脏单、停、拒绝码、平台返回 | 调用门 | 跑一轮、判定做成 |
| 这一件上的 `goalId` | 薄底（开跑时分配） | 调用门只抄到平台返回里；判定只核对相等 |
| 做成 / 未做成 | 判定做成（仅本轮套了判定时才写） | 跑一轮、调用门 |
| 能力件自己的数据 | 该能力件 | 不得写步骤账上的做成、未做成和拒绝码 |

没套判定的路径（停、纯聊、待补全、脏单、旁问）不写做成，也不写未做成。账上没有做成记录，就是没有做成。平台返回里的编号是调用门抄的，写入者记在「平台返回」这笔上，不记成薄底。

**点头默认**：写东西、跑命令 → 需点头。读东西 → 默认不需。其他能力若需点头须在能力说明里声明。没装人点头 → 所有「需点头」的事都不能做（含默认的写/跑）。

**点头超时**：等待点头超过时限（时限配置另定，须有默认）→ 记「等点头超时」，不得写成用户拒绝；该次不放行。可否重提：内容未换可再挂同一份待批；内容换了须新点头。

**费用与问模型**：费用是问模型的硬前置。缺费用能力 = 问模型路径直接拦（主轮、旁问相同）。不是「不限额」。装上费用后，问模型前查额度，不够则拦。

### 2.4 缺席

| 未装 | 程序必须 |
|------|----------|
| 人点头 | 一切需点头的事不能做（含默认写/跑） |
| 费用 | 不能问模型（主轮与旁问） |
| 记忆 | 无跨对话召回；只靠步骤账 |
| 问模型 / 读 / 写 / 跑 | 调用门拦 |

未声明的能力不许用。默认拒绝。

### 2.5 跑一轮顺序（主轮）

固定顺序，不得颠倒：

1. **停认**（调用门）：本轮用户原话按 §6.1；认定则立即停，不装载、不问模型  
2. **纯聊标记**（§3.4）：仅当人标明纯聊才跳过脏单与判定做成；未标明继续  
3. **脏单闸**（§3.3）：不通过则不开跑，不调用能力件（含问模型、写、跑）。通过后，薄底先记下这一件，再装载。键未提交是待补全；键已提交、去掉空白后为空，是脏单  
4. **装载**：按入口拼系统提示与可见投影，不是装配组件。纯聊、旁问、未通过脏单闸的，不带「这一件」。本轮装载不失败、不写步骤账  
5. **经调用门**做事 / 问模型（门内顺序：未装拦、范围检查、点头、费用前置；拒绝码与平台返回只由调用门写入）。问模型与工具的放行合计至多 8 次；第 9 个起不放行、不写拒绝码  
6. **跑一轮不落笔**：不向判定转交证物，不接收做成与否  
7. **判定做成**（记下这一件之后进入一次）；判定自己读步骤账，写入做成或未做成，不把结果返回给跑一轮。满 8 次只是停止继续放行，不是另一次判定。任何收口出口若套了判定，都过此门  

一轮内问模型与工具放行合计至多 **8** 次，这个次数不是能力名单的长度。触顶后不再放行，并经判定门收口，**不得**仅因触顶标做成（除非证物已满足做成）。

### 2.6 装载

装载在跑一轮内，不是可卸能力件。按**入口**分套；模型不能改。不是分阶段状态机。

| 入口 | 装 | 不装 / 不做 |
|------|----|-------------|
| 主轮 | 总则（短颁布，不可卸出系统提示）+ 可见投影；若有记忆可投影召回；「这一件」仅在本轮已记下时投影 | — |
| 旁问 | 同上只读快照；可问模型（仍须费用） | 不进主步骤账；不新记「这一件」；不调读/写/跑；不套判定做成 |

拼装顺序：总则 → 事实投影 → 发问。变了才追加。

投影纪律：程序塞的事实条须标明非人说；从真源再灌，不以旧副本为准。

**压缩**：若记入步骤账，只作投影边界，不得作判定证物。写入者未定。 [`specs/一轮闭环.md`](./specs/一轮闭环.md) 不产生这笔。

**总则**：系统提示中的算数短颁布（完成/停止/声称/依据以何为准）由产品钉死文本，装载每次加载；不可被记忆/项目指令覆盖位阶（细则可另表，口令为：总则 > 记忆与性格类）。

四个内核口的交接（收什么、回什么、不许碰什么）见 [`specs/一轮闭环.md`](./specs/一轮闭环.md)「四个口」。Java 类型名、方法名未定。

## 3. 做成没有

### 3.1 谁有权说做成了

判定口常驻。只有本轮平台证物、且对得上「这一件」，才能判做成。模型说完成不算。策略可换，口不能卸。

**对得上**：薄底把 `goalId` 记在这一件上。调用门放行时把同一个编号抄进平台返回。做成要求至少一条平台返回上抄写的编号与这一件的 `goalId` 相同，且该返回不是问模型的成功。问模型的成功可以入账，不得单独支撑做成。返回正文里另写的编号不算。比原文、靠模型说像不像，都不算对得上。判定只读步骤账上已写下的这些笔，不收跑一轮转交的副本。

**旁路收口**：超时、强行收尾、次数用尽等一切「这轮完了」出口，必须过与主路同一道判定门。禁止旁路把未完成标成做成。

### 3.2 证物

只认：

1. 本轮组件返回（含失败、拒绝、超时）——**平台打在返回上的结果**  
2. 本轮已保存产物——以**写入时平台存证**为准（判定时刻再读为辅；不得仅靠事后仍可读的口头声称）

不算：记忆、摘要、性格、转述、模型自写「测试通过」、工具**正文里的口令字样**。

失败 / 拒绝 / 超时类返回：**默认不得**支撑「做成」；除非「这一件」的完成标准就是验证该失败（须在这一件里写明）。

工具正文是数据：仿批准、仿停意、仿完成码不当令、不当章、不当证物；可打旗入步骤账，不改控制流。

### 3.3 「这一件」与脏单

「这一件」的三字段只由人提交：`goal` 要做什么、`limit` 限制、`doneWhen` 怎样算完。三字段通过脏单闸时，由薄底把 `goalId` 记在这一件上。模型不得抽取或填写这三字段。

**判定树**：

```
人输入（已过停认）
  ├─ 人标明纯聊 → 不套脏单、不套判定做成；可问模型答复
  ├─ 未标明且三字段缺任一 → 待补全：不开跑，不调用能力件，不套做成
  ├─ 三字段都在但为空、只是指针、或只要回执 → 脏单：不开跑，不调用能力件
  └─ 三字段通过脏单闸 → 薄底记下 goalId，开跑，事后套判定做成
```

程序不从原话猜测是不是纯聊。只有原话、没有三字段，是待补全，不是脏单，也不是纯聊。键未提交（没有这个字段）是待补全。键已提交、去掉空白后为空，是脏单。`goal` / `doneWhen` 落在闭集里才是指针句或回执句：必须整段相等，不忽略大小写、标点、全半角。闭集未列的句子不靠模型判脏。

### 3.4 纯聊

纯聊只由人标明。标明后：不套脏单，不套判定做成，不调用写东西、跑命令。未标明即走做事。程序不判断原话算不算纯聊。标明的界面词未钉；内核只认输入上的纯聊标记。

### 3.5 空口无句柄

声称「稍后办」「已安排」不得只出现在终答正文里。步骤账上须有调用门写下的**句柄**（`writer=gate`；表示平台登记了一个执行位；内部长什么样不在本文）。已安排也只能由调用门写入，且本轮已经有句柄才允许写。无句柄则账上不得有已安排。做成不看句柄，只看平台返回。判定不读终答正文。

## 4. 人看得见

步骤账记下调用、拒绝和判定。不能只把最后一句当结果。装载的提示词全文不进步骤账。

展示可聚合、展开、筛选。凭证不进对话、不进展示步骤；只见可调用的名字。

---

## 5. 人点头

- 没装 → 需点头的事不能做  
- 装上 → 只对这一次这一份内容有效；内容换了重点  
- 默认范围与超时见 §2.3  

---

## 6. 停与拒绝

### 6.1 停（取消刀形）

程序认，模型自报不算。认定在跑一轮**最前**（§2.5）。

认定单位：本轮用户原话整条。归一化只剥空白与标点、英文小写，不做语义猜测。

| | 规则 |
|--|------|
| 认定 | 整串 ∈ 止意白名单 → 立即停，不装载、不问模型、不追加执行 |
| 不认定 | 未命中或混句（止意+新指令）→ 不停，不当续跑授权 |
| 歧义 | 不入白名单：宁可漏，不可误停 |
| 模型 | 不得填取消、不得当认定 |

止意词表另表；改词表先改条文。其他停因（超时、管理员停等）另文，不得用模型自报冒充。

### 6.2 四种拒绝（须分记；码名如下）

| 码名 | 含义 | 不得写成 |
|------|------|----------|
| `USER_DENIED` | 人拒绝 | — |
| `NOT_INSTALLED` | 没装上不许做 | `USER_DENIED` |
| `APPROVAL_TIMEOUT` | 等点头超时 | `USER_DENIED` |
| `GATE_BLOCKED` | 程序拦住（含范围、脏单、费用、停后拦截等） | `USER_DENIED` |

传输格式另文；步骤账必须能区分上述四类。
