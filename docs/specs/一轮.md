# 一轮

总规则：[`../rewrite-1.md`](../rewrite-1.md) 第 2.5、2.6、3、4 节。结构：[`../agent-os.md`](../agent-os.md)。

本文只写 `round`。它按固定次序去问账、检查口、给模型看、判断，只写过程记录。它不问回答，也不问做事。

步骤记录里的写入者仍是 `gate`、`base`、`judge`。`base` 是账写下的那一笔。

## 本文管什么

**包括**

- 正题：认停止 → 是不是只聊天 → 字段 → 记下这次任务 → 给模型看 → 放行问模型 → 只认成功时旁边交来的工具，按顺序放行读、写、跑 → 模型不再交工具就不再问 → 判断。人交来的 `calls` 不看。回答正文里的行不执行。
- 旁边的工具是 `Read`、`Grep`、`Glob`、`Edit`、`Write`、`跑命令`。`Read` 按读东西记，`Write` 按写东西记。每一项自带目标。写和改再带要写入的字，查找再带式子，跑再带参数。这些字不使用人交的「要做什么」。只聊天和旁边问不认这些工具。正题、只聊天、旁边问都不读人交来的 `calls`。验收表里仍写读东西、写东西的，对的就是这两项。
- 验收表里写「成功正文是整行某某」的，指旁边交来的那一项。正文里出现同样的字，也不执行。
- `跑命令` 的参数每行一个。没有参数就只启动程序。不经过系统外壳，也不把参数拼成一条命令。参数里是绝对路径、带目录符、或带上级目录的，必须落在限制里，没过就拦住，不去问点头。普通参数不挡。工作目录用限制：限制是目录就在里面跑，限制是文件就在它所在的目录里跑。
- 挨在一起的 `Read`、`Grep`、`Glob` 是一批，按交来的顺序放行，不要求同时进行。`Write`、`Edit`、`跑命令` 各自单独一批。下一批开始前，上一批每一项的拒绝或平台返回必须已经写下。
- 人拒绝（`USER_DENIED`）或等同意超时（`APPROVAL_TIMEOUT`）时，这一篇里还没放行的点名都记跳过，不再放行。跳过的附注写能力名；有目标就写成「能力名 目标」。没装上，或范围拦住，只停这一项，后面的继续。
- 费用只扣在问模型。读、写、跑不扣。下一次问模型被费用拦住，仍是一次放行，记 `GATE_BLOCKED`，然后去判断。
- 人标明只聊天：不看字段，不记任务，不判断，不看名单，不认旁边的工具，不放行读、写、跑。人要问才放行一次问模型。
- 旁边问比只聊天先。不写正题的步骤记录，不另开一本，不判断，不放行读、写、跑。
- 问模型和工具加起来最多 8 次。第 9 次起不放行，过程记录记「跳过」。满 8 次不是做完。问模型不是成功，或旁边没有工具，就不再放行工具，也不再问。
- 判断不把做完交回。模型说的那句话不写入能力交回。问模型成功不能单独算做完。`Read`、`Grep`、`Glob` 的成功也不能。做完只认写东西、`Edit` 或跑命令对得上的成功返回。
- 正题不看 `askModel`，也不看 `calls`。正题在字段合格并记下任务之后自己放行问模型。`askModel` 只用于还没停的只聊天和旁边问。
- 停、是不是只聊天、三个字段，都不由模型的话来定。只聊天只看人有没有标明。
- 放行时，一轮把给模型看交回的几行原样交给检查口。读、写、跑还带上这一项的目标；写再带上要写入的字，跑再带上参数。限制用三个字段里的限制。给模型看的那几行不解析、不执行。
- 认停止和放行时，一轮另交一句：这次写不写入正题的步骤记录。旁边问一律传不写。检查口照这句做，不自己分辨正题、只聊天、旁边问。

**不包括**

- 停止词怎么对上，见 [回答.md](./回答.md)
- 费用、点头、范围怎么回答，见 [回答.md](./回答.md)
- 问模型、读、写、跑怎么做，见 [做事.md](./做事.md)
- 给模型的几行怎么拼，见 [给模型看.md](./给模型看.md)
- 怎样算做完，见 [判断.md](./判断.md)
- 外面怎么交、怎么读回，见 [对外.md](./对外.md)
- 同一次输入再提交、同一个任务编号再开跑，不在本文
- 执行登记里面长什么样、哪一种输入会写下它，不在本文。没有登记就不能出现「已安排」，见 V-11

正题，三个字段合格：

```mermaid
sequenceDiagram
  participant round as 一轮
  participant gate as 检查口
  participant ledger as 账
  participant view as 给模型看
  participant judge as 判断
  round->>gate: 认停止，写入正题：是
  gate-->>round: 继续
  round->>gate: 看三个字段
  gate-->>round: 可以开始
  round->>ledger: 记下这次任务
  ledger-->>round: 任务编号
  loop 还没满 8 次，并且这一圈还要问模型
    round->>view: 拼几行。带上这次任务，以及这次任务已经写下的返回和拒绝
    view-->>round: 那几行
    round->>gate: 放行问模型，写入正题：是，传入同一个任务编号，几行原样传入
    gate-->>round: 拒绝、失败、超时，或成功正文
    alt 不是成功，或正文没有整行点名
      Note over round: 不再放行工具，也不再问
    else 有点名
      loop 连续的读是一批。写、跑各自一批。下一批等上一批已经写下
        alt 再放行就会超过 8 次
          Note over round: 这一项和它后面的点名都记跳过，不再问
        else
          round->>gate: 放行这一项，写入正题：是，传入同一个任务编号、这一项的目标、限制
          gate-->>round: 拒绝代码或平台返回
          Note over round: 若是人拒绝或等同意超时，这一篇剩下的点名都记跳过。没装上或范围拦住，只停这一项
        end
      end
    end
  end
  round->>judge: 请判断，不传证据
  Note over judge: 自己读步骤记录。不把做完交回
```

旁边问：

```mermaid
sequenceDiagram
  participant round as 一轮
  participant gate as 检查口
  participant view as 给模型看
  round->>gate: 认停止，写入正题：否
  alt 停
    gate-->>round: 停
    Note over gate: 不把停写入正题步骤记录
  else 继续
    gate-->>round: 继续
    round->>view: 拼只读的几行，不带这次任务
    Note over round: 过程记录有「旁问」和「装载」
    opt 人要问模型
      round->>gate: 放行问模型，写入正题：否，不传任务编号，几行原样传入
      gate-->>round: 拒绝代码或平台返回
    end
  end
  Note over round: 不问账，不问判断。不放行读、写、跑
```

过程记录只由一轮写。步骤名只有这九个：认停、旁问、纯聊、未开跑、记下这一件、装载、放行、跳过、交判定。装载可以出现多次。每步可以带附注。附注不是另一个步骤名。

旁边问并且停：步骤名仍是认停，附注是「旁问停」。正题停：附注是「主轮停」。没停：附注是「继续」。旁边问还没停，另有一步「旁问」，并且有「装载」。只聊天还没停，有一步「纯聊」，并且有「装载」。字段没过，有一步「未开跑」，然后结束，没有装载。放行只记能力名，加上结果种类或拒绝代码。
