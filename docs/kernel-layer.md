```text
⑤ 应用        UI · Skill/记忆资产 · 面板
```

## 待验点（画图暴露、尚未裁决）

1. **总线不自动写会话日志**：TOOL 事件由 ③ 编排落 entries；备选=总线自动追加（journal 更强，但总线耦合事件类型）。
2. NEED_APPROVAL 现与 DENY 同命运（= C1 挂账）。
3. 未装配 Policy 默认 ALLOW（= C2 挂账）。
4. registers 无通用端口（= RegisterStore 挂账）。
