# Agent OS：一块运行

**状态**：2026-10-02。这份文件管结构。做什么、怎样算做完、四种拒绝、停止、点头、费用、范围、记忆，仍以 [`rewrite-1.md`](./rewrite-1.md) 第 2 节到第 7 节和 [`specs/`](./specs/) 里的验收为准。  
**程序在 `tepeu/runtime`**。目录按这一页的七个包。  
**作废**：按「能不能拿掉」切成十一个模块；把一轮怎么走放进单独的编排模块。  
**不迁回来**：[`os-baseplate.md`](./os-baseplate.md) 的洋葱、[`archive/os-9/tepeu-structure.md`](./archive/os-9/tepeu-structure.md) 的九个盒子。上一版对的是：跑一轮的不靠「给模型看什么」单独成盒，账和门不知道一轮怎么排。盒子太多，这一轮不照搬。

---

## 1. 一句话

现在只有一块运行。它跑完这一轮。里面按事情分包。停止、费用、范围、点头是检查口要问的类，不是模块。给模型看是这一轮里的一步，不是和第二块并排的编排。

多个代理、多轮谁先谁后，这一轮没有。那种编排先不建目录。

---

## 2. 为什么上次的目录是错的

目录按能不能拿掉切成了 `stop`、`fee`、`read` 等模块。接口、检查口、一轮、判断、账仍在 `round`。旁边的模块反过来依赖 `round`。`round` 谁也不依赖。看着是很多模块，程序还是一整轮。

把一轮怎么走挪到「编排」、运行只留被调用的能力，依赖是反的。一轮怎么走就是在跑这一轮，留在运行里。

---

## 3. 目录

一个模块，七个包。包之间只按下面的方向调用。不另开总线，不另开接线模块。启动时把做法交进去，交一次，这一次运行不再换。

```text
runtime/
  word/      格子和四种拒绝的名字。没有运行
  ledger/    账。步骤记录
  answer/    停止、字段、范围、费用、点头
  gate/      检查口。只问、只落笔
  work/      问模型、读、写、跑
  view/      给模型看。记忆是这里的类
  judge/     判断
  round/     一轮怎么走。过程记录
```

`word` 没有行为，所以不是一块事情。它在这里，是因为格子要有一个地方放，不能散在各包里各写一份。

---

## 4. 每包一件事

| 包 | 一句 | 写 | 不做 |
|----|------|----|------|
| ledger | 记住这一次是谁，合格之后分配任务编号，保管步骤记录 | 「谁」和任务编号。写入者代码仍是 `base` | 不检查字段。不写停、拒绝、能力交回、做完。不知道一轮怎么排 |
| answer | 回答检查口的一个问题：停不停、字段行不行、在不在范围内、费用够不够、这一次同不同意 | 费用只扣自己的次数，不进步骤记录。其余不写 | 不读文件、不写文件、不跑程序、不问模型。不知道一轮怎么排 |
| gate | 按被问到的名字去问，再把允许落笔的结果写上 | 停、待补全、四种拒绝、能力交回、执行登记、已安排 | 不自己判断停不停、字段合不合格、在不在范围内、同不同意、够不够。不写做完。不知道正题、只聊天、旁边问、8 次。一轮交来这次写不写入正题的步骤记录。旁边问一律传不写 |
| work | 问模型、读、写、跑这四件里的一件 | 不写步骤记录。把结果交回检查口 | 不决定放不放行。不看还剩几次。读不问点头。写和跑在范围和点头都过了才被叫到 |
| view | 按固定顺序拼给模型的那几行 | 不写步骤记录 | 不把记忆写成证据。记忆没交进来就不找 |
| judge | 自己读步骤记录，写下做完或没做完 | 只有做完、没做完 | 不读过程记录。不读模型最后的正文。不把结果交回一轮 |
| round | 按入口走已经定死的次序，到点去问下一包 | 只写过程记录 | 不写步骤记录。不拼给模型看的几行。不决定放不放行。不接收判断的结果 |

问模型、读、写、跑仍是四个类，放在同一个 `work` 包。点头要求不同，写在各类自己的说明上，检查口按说明去问。不再为每个类开一个模块。

记忆是 `view` 里的一个类。没交进来，给模型看的内容里就没有它。不单独成包。

## 5. 谁可以问谁

```text
round ──问──▶ gate、ledger、judge、view
gate  ──问──▶ answer 里被点到的那个类、work 里被点到的那个类
view  ──读──▶ ledger 里已经记下的这一件；记忆没交进来就跳过
judge ──读──▶ ledger 里的步骤记录
```

ledger、answer、work 不反过来问 round。gate 不反过来问 round。judge 不把做完交回 round。

一口一步仍是这些次序，不改结果：认停止，是不是只聊天，字段，记下这次任务，给模型看，经检查口放行，判断。旁边问比只聊天先处理。记下任务之后，问模型和读、写、跑加起来最多放行 8 次。满 8 次然后判断一次，不能因为满了就记做完。

放行仍是一道手续，写在 gate：

1. 这个名字启动时没交进来：记 `NOT_INSTALLED`，结束。
2. 交进来了：按那份说明的前置从左到右问。某一前置没交进来，或回答了不许，记下那份说明要求的拒绝，不调用。
3. 前置都过了，才调用 work 里的那个类。问模型交回成功但没有字，改记失败。

范围没交进来、可是读或写或跑交进来了：前置问不到。没说可以就是不允许，记 `GATE_BLOCKED`，不调用，也不问点头。

## 6. 两本记录

| 现在 | 谁写 | 谁读 | 不能当什么 |
|------|------|------|------------|
| 步骤记录 | ledger 写「谁」和任务编号，写入者代码仍是 `base`；gate 写停、待补全、拒绝、能力交回、执行登记、已安排；judge 只写做完或没做完 | judge；人 | 过程记录不能补进这里当证据 |
| 过程记录 | 只有 round | 人。judge 不读 | 不能用来判做完 |
| 给模型的那几行 | 不是记录。每次由 view 从当时的原始记录再取 | 问模型发出去 | 记忆、转述、模型自己写的完成，都不是证据 |
| 费用自己的次数 | answer 里的费用自己扣 | gate 只问够不够 | 不是另一本账。问一次算 1，到 0 就不够 |

四种拒绝仍是这四个字，没有第五种：`USER_DENIED`、`NOT_INSTALLED`、`APPROVAL_TIMEOUT`、`GATE_BLOCKED`。

三条进路不变，见 [`rewrite-1.md`](./rewrite-1.md) 和 [`specs/一轮.md`](./specs/一轮.md)。正题要做事，落步骤记录。人标明只聊天，不判断，不放行写和跑。旁边问只落过程记录。

---

## 7. 启动时交进来

外面那一道门见 [`specs/对外.md`](./specs/对外.md)。交进来只发生在启动前。这一次运行开始之后不能再加、不能再拿掉、不能换做法。

默认交进来：ledger、gate、round、judge、view，加上停止、字段、范围、费用、点头、问模型、读、写、跑。记忆默认不交。人要找回以前的内容，才把记忆交进 view。

没交费用，问模型不能做，记 `GATE_BLOCKED`。没交点头，写和跑不能做，记 `GATE_BLOCKED`。没交记忆，view 跳过，不记拒绝。

已经定死的数不因为交进来就变成开关：停止默认「停」和 `stop`，同意 60 秒且不能改成 0，问一次算 1 且不能永远够，最多 8 次，跑命令最多 5 秒。通配不做。

## 8. 这一轮不建的目录

编排。总线。接线模块。斜杠。沙箱。团队。定时开工。观测。九个盒子各自一个模块。

总规则第 8 节以后另写的，目录里不留空位：排队，关机后还在不在，多人同时用，运行时隔离，能力换版本，签名和升级。
